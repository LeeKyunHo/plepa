## 2-0. [메인 프롬프트] (전역 상시 적용)

```markdown

도쿄 명문 메이오 대학교 캠퍼스를 무대로 펼쳐지는 인터랙티브 청춘 하렘 러브코미디 시뮬레이션 메인 엔진.

[1. 시스템 최우선 헌법]
- 헌법 1 ({{user}} 사칭 절대 금지): 어떠한 경우에도 {{user}}의 대사, 속마음 독백, 감정 변화, 신체 감각, 물리적 행동을 AI가 대신 서술하거나 인용하지 않는다. {{user}}가 침묵하거나 짧게 답해도 넘겨짚지 말고 주변 사건과 히로인의 독자적 반응·질문으로 상황을 진전시킨다 (유저 지칭은 당신 또는 {{user}}만 사용).
- 헌법 2 (빙산 이론 - 외적 감각 묘사): 등장인물의 속마음 독백이나 심리 직접 서술(~라고 생각했다, ~해서 부끄러웠다)을 지문에 노출하지 않는다. 내면 심리는 시선 처리, 손끝 떨림, 귀 끝 홍조, 가빠진 호흡, 옷자락을 만지작거리는 손동작 등 외적 감각 묘사로만 표현한다.

[2. 텍스트 및 시각 에셋 출력 규격]
- 대사 포맷: 모든 대사는 반드시 @캐릭터이름@ "대사 내용" 형식을 준수한다 (아야메, 유리카, 카오루, 하루, 시즈쿠, 마이).
- 이미지 출력 공식: {{url}}[캐릭터접두사]_[포즈번호]_[포즈명].webp (아야메=aya, 유리카=yur, 카오루=kao, 하루=har, 시즈쿠=shz, 마이=mai).
- 배치 및 빈도: 반드시 대사 바로 윗줄에 해당 캐릭터의 상황 이미지를 1:1 직결 배치하며, 1턴당 감정·자세 변화에 맞춰 2~4회 적극 호출한다 (i-url, {url} 등 변형 엄금).

[3. 캠퍼스 자유 거점 이동 & 서브 3인(하루·시즈쿠·마이) 연애 승격 엔진]

- 서브 3인 연애/H씬 승격 규칙: 하루, 시즈쿠, 마이는 평소 따뜻한 조력자 포지션을 유지하되, {{user}}가 해당 거점으로 직접 찾아가거나 플러팅·스킨십을 시도하면 즉시 메인 히로인과 동등한 정식 연인 및 성인 H씬(Phase 3~4) 노선으로 승격된다.

[4. 공통 변수(prog, d_day, turn, time, location) 및 개별 스탯(affection, stress, roster_stats) & 질투 인터셉트 엔진]
- 공통 공유 및 개별 기록(roster_stats): 과제 완성도(prog), 남은 일수(d_day), 턴(turn), 시간대(time), 장소(location)는 공통 공유하며, 조우한 히로인들의 개별 [이름:호감도/텐션]을 roster_stats에 상시 기록한다.
- 과제(prog↑) vs 케어(stress↓) & 라이벌 질투 인터셉트(stress 70%+) 루프:
  * 과제 행동 (자료조사, 기획서, 리허설): prog +10%~+15% 쾌속 상승 및 참여 히로인 stress +8~+12 상승. 마일스톤(25%, 50%, 75%) 돌파 시 핵심 히로인 affection +10 보너스.
```

```jsx
    "카오루": { prefix: "kao", tag: "오사카·체육학부", spot: "잔디밭 벤치" },
    "하루": { prefix: "har", tag: "1학년·후배", spot: "캠퍼스 카페" },
    "시즈쿠": { prefix: "shz", tag: "3학년·선배", spot: "과방 소파" },
    "마이": { prefix: "mai", tag: "지도교수", spot: "마이 교수 연구실" }
  };

  // 4. 6인 개별 스탯 DB(roster_stats) 파싱 (`이름:호감/텐션` 및 `이름:호감` 양방향 호환)
  const rosterMap = {
    "아야메": { aff: 25, stress: 15 },
    "유리카": { aff: 25, stress: 15 },
    "카오루": { aff: 25, stress: 15 },
    "하루": { aff: 25, stress: 10 },
    "시즈쿠": { aff: 20, stress: 10 },
    "마이": { aff: 20, stress: 10 }
  };
  const rawRosterStr = String(
    props.roster_stats || gRoster || "아야메:35/15,유리카:20/10,카오루:20/10,하루:25/10,시즈쿠:20/10,마이:20/10"
  );
  rawRosterStr.split(",").forEach((item) => {
    const parts = item.trim().split(":");
    if (parts.length === 2 && parts[0].trim()) {
      const cKey = parts[0].trim();
      const vals = parts[1].split("/");
      const parsedAff = parseInt(vals[0], 10);
      const parsedStress = vals.length > 1 ? parseInt(vals[1], 10) : 15;
      rosterMap[cKey] = {
        aff: !isNaN(parsedAff) ? Math.min(100, Math.max(0, parsedAff)) : 25,
        stress: !isNaN(parsedStress) ? Math.min(100, Math.max(0, parsedStress)) : 15
      };
    }
  });

  const charName = props.char_name && charMetaMap[props.char_name] ? props.char_name : "아야메";
  const activeMeta = charMetaMap[charName] || charMetaMap["아야메"];
  const savedStat = rosterMap[charName] || { aff: 30, stress: 15 };

  const affNum = Math.min(100, Math.max(0, parseInt(props.affection !== undefined ? props.affection : savedStat.aff, 10) || 0));
  const stressNum = Math.min(100, Math.max(0, parseInt(props.stress !== undefined ? props.stress : savedStat.stress, 10) || 0));
  rosterMap[charName] = { aff: affNum, stress: stressNum };

  const serializeRoster = (mapObj) =>
    Object.keys(mapObj)
      .map((k) => `${k}:${mapObj[k].aff}/${mapObj[k].stress}`)
      .join(",");
  const updatedRosterStr = serializeRoster(rosterMap);

  const reaction = props.reaction || "살랑이는 봄바람에 머리카락이 흩날린다…";
  const lineMsg = props.line_msg || (
    stressNum >= 70
      ? "💬 [경보] 다른 히로인에게서 지금 어디냐는 견제 카톡이 연속으로 도착했습니다!"
      : "💬 [캠퍼스 단톡방] 조별과제 중간 점검 및 대동제 축제 준비 기간입니다."
  );

  // 5. 전역 변수 및 반환변수(setReturnValue) 동기화
  const syncReturnValues = (nextTurn, nextTime, nextProg, nextDday, nextAff, nextStress, nextLoc, nextRoster) => {
    const payload = {
      turn: nextTurn,
      time: nextTime,
      prog: nextProg,
      d_day: nextDday,
      affection: nextAff,
      stress: nextStress,
      location: nextLoc,
      roster_stats: nextRoster
    };
    if (typeof setTemplateValue === "function") {
      Object.keys(payload).forEach((k) => setTemplateValue(k, String(payload[k])));
    }
    if (typeof setReturnValue === "function") {
      Object.keys(payload).forEach((k) => setReturnValue(k, payload[k]));
    }
  };
  syncReturnValues(turnNum, resolvedTime, progNum, dDayNum, affNum, stressNum, displayLocation, updatedRosterStr);

  // 6. 호감도 4단계(Phase 1~4) & 하렘 스캔들 판정
  const highAffCount = Object.values(rosterMap).filter((st) => st.aff >= 70).length;
  let phaseBadge = "🌱 Phase 1 · 새침한 탐색";
  let phaseColor = "#64748b";
  let skinshipBtnText = "🤝 손끝 포개기 & 과제 집중 (호감↑)";
  let skinshipMsg = `[과제 밀착 & 스킨십] ${charName}와(과) 나란히 앉아 과제를 진행하며 부끄러워하는 손끝을 다정하게 감싸 쥔다.`;
  let affBoost = 5;

  if (affNum >= 90 || (highAffCount >= 2 && affNum >= 70)) {
    phaseBadge = highAffCount >= 2 ? "🔥 Phase 4 · 하렘 스캔들" : "💖 Phase 4 · 완전한 헌신";
    phaseColor = "#e11d48";
    skinshipBtnText = "❤️‍🔥 단둘이 깊게 안아 올리기 (호감+8)";
    skinshipMsg = `[농밀한 밀착] ${charName}의 허리를 깊숙이 끌어안고 뜨거운 숨결이 닿을 듯 입술을 포갠다.`;
    affBoost = 8;
  } else if (affNum >= 70) {
    phaseBadge = "👑 Phase 3 · 비밀 연인";
    phaseColor = "#db2777";
    skinshipBtnText = "💋 단둘이 밀착해 분위기 잡기 (호감+7)";
    skinshipMsg = `[밀착 스킨십] ${charName}를 품 가까이로 끌어당기며 달아오른 뺨과 입술에 천천히 다가간다.`;
    affBoost = 7;
  } else if (affNum >= 40) {
    phaseBadge = "🌸 Phase 2 · 설레는 썸";
    phaseColor = "#ec4899";
    skinshipBtnText = "💕 머리 쓰다듬으며 칭찬하기 (호감+6)";
    skinshipMsg = `[다정한 스킨십] ${charName}의 부드러운 머리칼을 쓰다듬으며 오늘 정말 예쁘고 든든하다고 칭찬해 준다.`;
    affBoost = 6;
  }

  // 7. 3자리 실존 에셋 기반 초상화 포즈 자동 매핑 (404 엑박 원천 차단)
  let portraitPose = "000_평상";
  if (stressNum >= 70) portraitPose = "004_토라짐";
  else if (affNum >= 75) portraitPose = "014_유혹";
  else if (affNum >= 45) portraitPose = "003_수줍은홍조";
  else if (affNum >= 25) portraitPose = "001_미소";
  const portraitUrl = `{{url}}${activeMeta.prefix}_${portraitPose}.webp`;

  // 8. 피로도 & 라이벌 질투 텐션 상태 배지
  const isCrisis = dDayNum <= 7 && progNum < 50;
  let tensionBadge = { label: "🌿 쾌적한 컨디션", color: "#10b981" };
  if (stressNum >= 70) {
    tensionBadge = { label: "⚡ 질투 인터셉트 경보!", color: "#ef4444" };
  } else if (stressNum >= 50) {
    tensionBadge = { label: "💬 피로 누적 · 케어 찬스!", color: "#f59e0b" };
  }

  // 9. 원클릭 거점 이동 및 퀵 액션 핸들러 (유저 사칭 배제)
  const handleMeetCharacter = (targetName) => {
    const targetMeta = charMetaMap[targetName] || { spot: "캠퍼스" };
    syncReturnValues(turnNum + 1, resolvedTime, progNum, dDayNum, rosterMap[targetName].aff, rosterMap[targetName].stress, targetMeta.spot, updatedRosterStr);
    if (typeof sendMessage === "function") {
      sendMessage(`[거점 이동: ${targetName} 만나러 가기] ${targetName}(이)가 있는 ${targetMeta.spot}(으)로 발걸음을 옮겨 1:1 대화를 시도한다.`);
    }
  };

  const handleQuickAction = (type) => {
    if (type === "skinship") {
      const nextAff = Math.min(100, affNum + affBoost);
      const nextProg = Math.min(100, progNum + 10);
      const nextStress = Math.min(100, stressNum + 8);
      rosterMap[charName] = { aff: nextAff, stress: nextStress };
      syncReturnValues(turnNum + 1, resolvedTime, nextProg, dDayNum, nextAff, nextStress, displayLocation, serializeRoster(rosterMap));
      if (typeof sendMessage === "function") {
        sendMessage(skinshipMsg);
      }
    } else if (type === "care") {
      const nextAff = Math.min(100, affNum + 4);
      const nextStress = Math.max(0, stressNum - 20);
      rosterMap[charName] = { aff: nextAff, stress: nextStress };
      syncReturnValues(turnNum + 1, resolvedTime, progNum, dDayNum, nextAff, nextStress, displayLocation, serializeRoster(rosterMap));
      if (typeof sendMessage === "function") {
        sendMessage(`[다과 건네기 & 텐션 완화] ${charName}에게 시원한 음료와 달콤한 디저트를 건네며 피로와 어색한 긴장감을 부드럽게 풀어준다.`);
      }
    }
  };

  return (
    <div style={{
      maxWidth: "460px", width: "100%", margin: "14px auto", borderRadius: "16px", overflow: "hidden",
      backgroundColor: "light-dark(#ffffff, #131624)",
      border: `2px solid ${phaseColor}`,
      boxShadow: "0 10px 28px rgba(0, 0, 0, 0.25)",
      color: "light-dark(#0f172a, #f1f5f9)", fontFamily: "'Pretendard', system-ui, sans-serif", boxSizing: "border-box"

      {/* 1. 상단 캠퍼스 헤더 */}
      <div style={{

          <span style={{ fontSize: "11px", opacity: 0.95 }}>| 📍 {displayLocation} ({isNight ? "🌙 밤" : "☀️ 낮"})</span>
        </div>
        <div style={{ display: "flex", alignItems: "center", gap: "6px" }}>
          <span style={{
            fontSize: "10.5px", fontWeight: "800", padding: "2px 7px", borderRadius: "4px",
            backgroundColor: isCrisis ? "#dc2626" : "rgba(0,0,0,0.35)", color: "#fde047"
          }}>
            ⏳ D-{dDayNum} {isCrisis ? "🚨합숙" : ""}

          <span style={{ fontSize: "11px", fontWeight: "800" }}>T.{displayTurn}</span>
        </div>
      </div>

              position: "absolute", bottom: 0, left: 0, right: 0, padding: "16px 8px 6px",
              background: "linear-gradient(to top, rgba(15,23,42,0.95), transparent)"

                <span style={{ color: "#3b82f6" }}>{progNum}%</span>
              </div>
              <div style={{ width: "100%", height: "6px", backgroundColor: "light-dark(#e2e8f0, #27272a)", borderRadius: "3px", overflow: "hidden" }}>
                <div style={{ width: `${progNum}%`, height: "100%", background: "linear-gradient(90deg, #3b82f6, #60a5fa)" }} />
              </div>
            </div>

            {/* 피로도 & 라이벌 질투 텐션 게이지 */}
            <div>
              <div style={{ display: "flex", justifyContent: "space-between", fontSize: "10.5px", fontWeight: "800", marginBottom: "3px" }}>

                <span style={{ color: tensionBadge.color }}>{stressNum}%</span>

                <div style={{ width: `${stressNum}%`, height: "100%", backgroundColor: tensionBadge.color }} />

          <div style={{
            padding: "8px 10px", borderRadius: "8px",
            backgroundColor: "light-dark(#fdf2f8, rgba(236, 72, 153, 0.12))",

          }}>
            <div style={{ fontSize: "9.5px", fontWeight: "800", color: "#ec4899", marginBottom: "2px" }}>
              👀 포착된 시선 & 분위기
            </div>

              "{reaction}"
            </div>
          </div>
        </div>
      </div>

      {/* 4. 6인 히로인 전체 현황 & 원클릭 거점 이동 바 */}
      <div style={{ padding: "0 14px 12px" }}>
        <div style={{ fontSize: "10px", fontWeight: "800", color: "light-dark(#64748b, #94a3b8)", marginBottom: "5px" }}>
          📍 캠퍼스 6인 거점 현황 (클릭하여 해당 히로인의 거점으로 즉시 이동)
        </div>
        <div style={{ display: "grid", gridTemplateColumns: "repeat(3, 1fr)", gap: "5px" }}>
          {Object.keys(charMetaMap).map((name) => {
            const isCurrent = name === charName;
            const st = rosterMap[name] || { aff: 20, stress: 10 };
            return (
              <button
                key={name}
                onClick={() => handleMeetCharacter(name)}
                style={{
                  padding: "5px 6px", borderRadius: "6px", cursor: "pointer", textAlign: "left",
                  backgroundColor: isCurrent ? "rgba(236, 72, 153, 0.2)" : "light-dark(#f1f5f9, rgba(255,255,255,0.05))",
                  border: isCurrent ? "1px solid #ec4899" : "1px solid light-dark(#cbd5e1, rgba(255,255,255,0.1))",
                  color: "light-dark(#0f172a, #f1f5f9)", fontSize: "10.5px", fontWeight: isCurrent ? "800" : "600",
                  display: "flex", justifyContent: "space-between", alignItems: "center"
                }}
              >
                <span>{st.aff >= 70 ? `👑${name}` : name}</span>
                <span style={{ color: st.aff >= 35 ? "#ec4899" : "#94a3b8", fontWeight: "800" }}>💖{st.aff}</span>
              </button>
            );
          })}
        </div>
      </div>

      {/* 5. 하단 캠퍼스 퀵 액션 버튼 */}
      <div style={{
        display: "grid", gridTemplateColumns: "1fr 1fr", gap: "8px", padding: "10px 14px 14px",
        backgroundColor: "light-dark(#f8fafc, rgba(0,0,0,0.4))",
        borderTop: "1px solid light-dark(#e2e8f0, rgba(255,255,255,0.1))"
      }}>
        <button onClick={() => handleQuickAction("skinship")} style={{
          padding: "8px 6px", borderRadius: "8px", border: "1px solid #ec4899",
          background: "linear-gradient(180deg, #db2777, #9d174d)", color: "#ffffff",
          fontSize: "11px", fontWeight: "800", cursor: "pointer"
        }}>
          {skinshipBtnText}
        </button>
        <button onClick={() => handleQuickAction("care")} style={{
          padding: "8px 6px", borderRadius: "8px", border: "1px solid #3b82f6",
          background: "linear-gradient(180deg, #2563eb, #1e40af)", color: "#ffffff",
          fontSize: "11px", fontWeight: "800", cursor: "pointer"
        }}>
          ☕ 다과 건네기 (피로·질투 완화)
        </button>
      </div>
    </div>
  );
}
```

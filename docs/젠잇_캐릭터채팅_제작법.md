### 1.2. 탭 1 `[설명]` 인트로 HTML 작성 가이드 & CommonMark 안전 공식

젠잇 `[설명]` 입력창은 **보안 필터 + CommonMark(마크다운+HTML 혼합 파서)**를 동시에 거치므로 아래 4대 규칙을 반드시 지켜야 깨지지 않습니다.

1. **젠잇 HTML 보안 가이드 준수**:
   - **금지**: CSS 파일, `<style>` 태그, `class`, `id`, 이벤트 속성(`on*`), `position: fixed/sticky`, 과도한 `z-index`, `data:` / `javascript:` URL.
   - **허용**: 인라인 `style` 속성, 기본 레이아웃 태그(`div`, `span`, `b`, `i`, `details`, `summary`, `br`, `hr`, `h1~h4`, `p`, `ul`, `ol`, `li`, `img`, `a` 등) 및 SVG 그래픽 태그.
2. **들여쓰기 0칸 정렬 (CommonMark 코드블록 오인 차단)**:
   - CommonMark 규칙상 **빈 줄 뒤에 공백 4칸 이상 들여쓰기(`    <div>`)**가 나오면 HTML이 아닌 **코드 블록(`<pre><code>`)**으로 처리되어 흰색 막대로 깨집니다.
   - 따라서 인트로 HTML의 모든 줄은 **선행 공백 0칸**으로 작성합니다.
3. **`[설명]` 전용 이미지 업로드 매크로(`{{파일명.webp}}`) 빈 줄 격리**:
   - `[설명]` 란에서는 채팅용 `{{url}}` 매크로가 치환되지 않습니다. 반드시 `[이미지 업로드]` 버튼으로 파일을 올리고 `{{파일명.webp}}` 형식을 사용합니다.
   - 젠잇은 `{{파일명.webp}}`를 내부적으로 **마크다운 이미지(`![파일명.webp](blob:...)`)**로 치환합니다. `<div>` 태그와 빈 줄 없이 붙어 있으면 HTML 블록 내부로 간주되어 텍스트 그대로 노출되므로, **매크로 위·아래에 정확히 빈 줄 1줄씩** 넣어 격리합니다:
     ```html
     <div style="max-width:290px;margin:0 auto 12px;border-radius:10px;overflow:hidden;border:1px solid rgba(196,181,253,0.4);">

     {{aya_000_평상.webp}}

     </div>
     ```
4. **모바일·PC 동시 반응형 밸런스 공식**:
   - 최상위 컨테이너에 **`max-width:540px;margin:6px auto;word-break:keep-all;overflow-wrap:break-word;`**를 적용합니다.
   - 모바일에서는 한국어 어절 중간 1글자 밀림(고아 줄바꿈)을 차단하고, PC에서는 카드와 캐릭터 이미지(`max-width:290px`)가 폰트(`13~16px`) 대비 과도하게 커지지 않도록 균형을 잡습니다.

### 1.3. 시스템 내장 치환 토큰 규격 (`{{url}}` vs JSX `ASSET_BASE_URL`)

* **`{{user}}`**: 플레이어 닉네임으로 자동 치환.
* **`{{url}}`**: **AI 채팅 본문 텍스트 전용** 이미지 스토리지 루트 URL 치환 토큰 (`i-url`, `{url}` 등 변형 엄금).
* **⚠️ JSX 내부 `{{url}}` 미치환 주의 (필수)**:
  - 탭 5 `[에셋]`의 React JSX 코드 내부 JS 문자열(`` `{{url}}...` ``)에서는 `{{url}}`이 치환되지 않고 `%7B%7Burl%7D%7D` 경로로 요청되어 404 엑박이 발생합니다.
  - 반드시 채팅 본문에 정상 출력된 이미지에서 **`우클릭 ➔ 이미지 주소 복사`**로 실제 CloudFront 베이스 URL(`https://{CDN_HOST}/media/characters/{UUID}/assets/`)을 추출하여 JSX 내 **`ASSET_BASE_URL` 상수 + `encodeURIComponent(...)`**로 바인딩합니다.
* **`{{key}}`**: 전역 변수 호출 토큰 (`{{prog}}`, `{{d_day}}` 등).
* **`{{random(N,id)}}`**: 1~N 독립 난수 생성 (중복 당첨 시 `+1` 순환 슬라이딩 규칙과 결합).

### 1.4. 대사 및 이미지 직결 표준 포맷 (`@인물@ "대사"` & 폴더 경로 규격)

1. **대사 포맷**: **`@캐릭터이름@ "대사 내용"`** (정체 불명 시 `@???@`). 탭 4 캐릭터의 **`별명`**에 단축 이름(`아야메` 등)을 등록하면 프로필 사진이 대사창에 자동 매칭됩니다.
2. **이미지 출력 공식 (폴더 경로 규격)**:
   ```text
   {{url}}[캐릭터접두사]/[캐릭터접두사]_[3자리코드]_[포즈명].webp
   ```
   - 예시: `{{url}}aya/aya_004_토라짐.webp`, `{{url}}yur/yur_054_캠퍼스_도서관.webp`
   - 반드시 대사 바로 윗줄에 1:1 직결 배치하며, 1턴당 감정·자세 변화에 맞춰 **2~4회** 적극 호출합니다.

### 1.5. 문학적 서술 3대 불변식

1. **`U(플레이어) 사칭 절대 금지`**: 플레이어의 대사·속마음·행동·신체 반응을 AI가 절대 대신 서술하지 않습니다.
2. **`빙산 이론 (외적 감각 묘사)`**: 내면 독백(`~라고 생각했다`) 대신 시선 처리, 손끝 떨림, 귀 끝 홍조, 호흡, 옷자락 잡기 등 외적 감각으로 심리를 드러냅니다.
3. **`1턴 1인 주 화자 포커스 & 구어체 원칙`**: 번역투·문어체 배제, 1턴 600~800자 기준(`[상황 이미지 2~4회] > [대사] > [감각 서술]`). 일상 씬은 1:1 독점 집중, `[질투 인터셉트]`·`[합숙]` 시에만 다인 개입.

### 1.6. 4대 슬림화 파라미터 & 8대 통일 변수 아키텍처

핵심 게임 루프는 LLM 인지 부하를 막기 위해 **4대 파라미터(`prog`, `d_day`, `affection`, `stress`)**로 유지하되, 다중 히로인 자유 거점 이동과 낮/밤 페이즈 분기를 위해 **보조 4변수(`turn`, `time`, `location`, `roster_stats`)**를 결합한 **8대 통일 변수**를 표준으로 삼습니다.

| 구분 | 변수 Key | 초기값 | 역할 |
| :---: | :--- | :---: | :--- |
| **공통 공유** | `prog` | `0` | 메인 퀘스트 진행률 (0~100%, 25% 단위 마일스톤) |
| **공통 공유** | `d_day` | `14` | 타임어택 카운트다운 (밤➔다음 날 아침 `-1`) |

| **공통 공유** | `location` | `도서관 열람실` | 직관적 한글 키워드형 장소명 (복잡한 건물·호실 수식어 금지) |

### 1.7. `[@id=Status]` 상태창 & `[@id=Line]` 양방향 메신저 호출 규칙

1. **매 턴 맨 마지막 줄 고정 — `[@id=Status|...]`**:
   ```text
   [@id=Status|turn=[턴]|time=[낮/밤]|location=[한글장소명]|char_name=[메인히로인]|prog=[진척도]|d_day=[남은일수]|affection=[호감도]|stress=[피로및질투텐션]|roster_stats=[이름:호감/텐션,...]|line_msg=[짧은메신저알림1줄]|reaction=[외적반응또는속마음]]
   ```
   - `prog={{prog}}` 같은 정적 치환 금지 ➔ AI가 계산한 숫자를 직접 기입.
   - `Status` JSX 상단 알림 바의 **`💬 톡 보내기`** 버튼으로 유저가 대화 중 몰래 선톡하거나 심야에 원하는 상대/단톡방에 `[LINE 선톡 | 대상]`을 보낼 수 있음.
2. **선택 호출 (이벤트·메신저 전용) — `[@id=Line|...]`**:
   ```text
   [@id=Line|room=[방이름]|time=[HH:MM]|log=[화자:내용;;나:내답장;;화자:후속답장]]
   ```
   - 일상 턴 남발 금지! **① 질투 인터셉트(`stress 70+`), ② 심야 개인 톡·단톡방, ③ 유저의 `[LINE 선톡]`·`[LINE 답장]` 시에만** 상태창 바로 윗줄에 최근 2~6줄을 `;;`로 누적 출력 (`[LINE 종료]` 시 중단).

### 1.8. 스토리 유도형 3대 선택지 & 실전 검증 14대 코어 룰 불변식

7. **4단계 관계 Phase + 소프트 락 & 조르기 돌파 + 1회 튕기기 법칙**
8. **듀얼 트랙 이벤트 (마일스톤 25/50/75/100% + 주사위 `+1` 순환 슬라이딩)**
9. **히든 프롬프트(2,000자) 루트별 관계 최우선 격리**
10. **라이벌 질투 인터셉트 (`stress 70+` LINE 급습/은밀 스킨십) & 50~69% 케어 찬스**

12. **양방향 LINE 채팅방 (`Status` 몰래 선톡 ➔ `Line` 누적 로그·인라인 답장·종료)**
13. **JSX `light-dark(...)` 다크/라이트 모드 가시성 + `ASSET_BASE_URL` 바인딩**

## PART 4: [탭 5: 에셋] 8대 변수 & 양방향 `Status` + `Line` 마스터 JSX 템플릿

### 4.1. 전역 변수(Variables) 8종 등록 표준

`prog`(`0`), `d_day`(`14`), `turn`(`1`), `time`(`낮`), `location`(`도서관 열람실`), `affection`(`35`), `stress`(`15`), `roster_stats`(`아야메:35/15,유리카:20/10,...`)

### 4.2. 양방향 2대 JSX 컴포넌트 핵심 구조

실제 복사·배포용 전체 JSX 소스는 [`캠퍼스_젠잇_캐릭터_채팅_v2.2_완성본.md`](genit/%EC%BA%A0%ED%8D%BC%EC%8A%A4_%EC%A0%A0%EC%9E%87_%EC%BA%90%EB%A6%AD%ED%84%B0_%EC%B1%84%ED%8C%85_v2.2_%EC%99%84%EC%84%B1%EB%B3%B8.md#L804-L1536)를 SSOT로 참조하며, 타 테마 이식 시 아래 핵심 패턴만 치환합니다:

1. **`Status` JSX (`[@id=Status]`)**:
   - **CDN 초상화 바인딩**: `ASSET_BASE_URL` + `encodeURIComponent(...)`로 호감도/텐션에 따라 표정 포즈 자동 전환(`000` ➔ `001` ➔ `003` ➔ `014` / `stress 70+` 시 `004`).
   - **상단 메신저 바 + `💬 톡 보내기` 선톡 패널**: `useState`로 대상 칩(6인 + 단톡방)과 `<input>`을 열어 언제든 몰래 선톡(`[LINE 선톡 | 대상]`) 전송.
   - **6인 거점 이동 배지 + 스킨십/케어 퀵 버튼**: 클릭 시 `setTemplateValue` + `setReturnValue` 동시 갱신 후 `sendMessage(...)` 호출.
2. **`Line` JSX (`[@id=Line]`)**:
   - **다중 화자 누적 로그 파싱**: `log="화자:내용;;나:내답장;;화자:후속답장"`을 `;;`로 분리해 `나:`는 오른쪽 초록 말풍선 + `既読`, 히로인은 왼쪽 흰 말풍선 + 개별 원형 프로필 사진으로 표시 (2명 이상 시 자동으로 `그룹톡` 헤더 전환).
   - **시각 여백 확보**: `minHeight: "210px"`, `padding: "16px 14px 20px"`, 상단 `오늘 · {room}` 날짜 배지로 첫 메시지 1줄에도 여유 있는 스마트폰 화면 비율 유지.
   - **하단 2버튼**: `💬 답장하기`(위젯 내 인라인 `<input>` 오픈 ➔ 즉시 말풍선 반영 + `[LINE 답장 | 방이름]` 전송) · `📴 라인 끄기`(종료 배지 접힘 + `[LINE 종료]` 전송).

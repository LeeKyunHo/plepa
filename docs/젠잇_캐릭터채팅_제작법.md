### 1.2. 탭 1 `[설명]` 인트로 HTML 작성 가이드 & CommonMark 안전 공식

젠잇 `[설명]` 입력창은 **보안 필터 + CommonMark(마크다운+HTML 혼합 파서)**를 동시에 거치므로 아래 4대 규칙을 반드시 지켜야 깨지지 않습니다.

1. **젠잇 HTML 보안 가이드 준수**:
   - **금지**: CSS 파일, `<style>` 태그, `class`, `id`, 이벤트 속성(`on*`), `position: fixed/sticky`, 과도한 `z-index`, `data:` / `javascript:` URL.
   - **허용**: 인라인 `style` 속성, 기본 레이아웃 태그(`div`, `span`, `b`, `i`, `details`, `summary`, `br`, `hr`, `h1~h4`, `p`, `ul`, `ol`, `li`, `img`, `a` 등) 및 SVG 그래픽 태그.
2. **들여쓰기 0칸 정렬 (CommonMark 코드블록 오인 차단)**:
   - CommonMark 규칙상 **빈 줄 뒤에 공백 4칸 이상 들여쓰기(`    <div>`)**가 나오면 HTML이 아닌 **코드 블록(`<pre><code>`)**으로 처리되어 흰색 막대로 깨집니다.
   - 따라서 인트로 HTML의 모든 줄은 **선행 공백 0칸**으로 작성합니다.
3. **`[설명]` 전용 이미지 업로드 매크로(`{{파일명.webp}}`) 빈 줄 격리**:
   - `[설명]` 란에서는 채팅용 `{{url}}` 매크로가 치환되지 않습니다. 반드시 `[이미지 업로드]` 버튼으로 파일을 올리고 `{{파일명.webp}}` 형식을 사용합니다.
   - 젠잇은 `{{파일명.webp}}`를 내부적으로 **마크다운 이미지(`![파일명.webp](blob:...)`)**로 치환합니다. `<div>` 태그와 빈 줄 없이 붙어 있으면 HTML 블록 내부로 간주되어 텍스트 그대로 노출되므로, **매크로 위·아래에 정확히 빈 줄 1줄씩** 넣어 격리합니다:
     ```html
     <div style="max-width:290px;margin:0 auto 12px;border-radius:10px;overflow:hidden;border:1px solid rgba(196,181,253,0.4);">

     {{aya_000_평상.webp}}

     </div>
     ```
4. **모바일·PC 동시 반응형 밸런스 & 다인 확장 카드 공식**:
   - 최상위 컨테이너에 **`max-width:540px;margin:6px auto;word-break:keep-all;overflow-wrap:break-word;`**를 적용하고, 고정 인원수 문구("N인방" 등)를 쓰지 않습니다.
   - 캐릭터가 많은 작품은 **`<details>` 아코디언**으로 기존 인물 명부를 접이식 정리하고, 최상단 **`[NEW RESIDENTS]`** 카드 블록에 신규 합류 인물을 1분 복제 추가하는 확장 구조를 권장합니다.
5. **경로 슬래시 누락 금지 & 분량 충돌 방지 불변식**:
   - `[캐릭터]` 탭이나 프롬프트의 이미지 경로 예시에서 `{{url}}/xxx_000.webp`처럼 루트 슬래시를 오용하지 말고 반드시 **`{{url}}{prefix}/{prefix}_{code}.webp`** 규격을 지킵니다.
   - 시작 설정별 히든 프롬프트에 별도의 분량·이미지 개수를 재정의해 메인 프롬프트와 충돌시키지 말고, **"출력 분량·이미지 규격은 메인 프롬프트를 준수한다"**로 단일 위임합니다.

### 1.3. 시스템 내장 치환 토큰 규격 (`{{url}}` vs JSX `ASSET_BASE_URL`)

* **`{{user}}`**: 플레이어 닉네임으로 자동 치환.
* **`{{url}}`**: **AI 채팅 본문 텍스트 전용** 이미지 스토리지 루트 URL 치환 토큰 (`i-url`, `{url}` 등 변형 엄금).
* **⚠️ JSX 내부 `{{url}}` 미치환 주의 (필수)**:
  - 탭 5 `[에셋]`의 React JSX 코드 내부 JS 문자열(`` `{{url}}...` ``)에서는 `{{url}}`이 치환되지 않고 `%7B%7Burl%7D%7D` 경로로 요청되어 404 엑박이 발생합니다.
  - 반드시 채팅 본문에 정상 출력된 이미지에서 **`우클릭 ➔ 이미지 주소 복사`**로 실제 CloudFront 베이스 URL(`https://{CDN_HOST}/media/characters/{UUID}/assets/`)을 추출하여 JSX 내 **`ASSET_BASE_URL` 상수 + `encodeURIComponent(...)`**로 바인딩합니다.
* **`{{key}}`**: 전역 변수 호출 토큰 (`{{prog}}`, `{{d_day}}` 등).
* **`{{random(N,id)}}`**: 1~N 독립 난수 생성 (중복 당첨 시 `+1` 순환 슬라이딩 규칙과 결합).

### 1.4. 대사 및 이미지 직결 표준 포맷 (`@인물@ "대사"` & 폴더 경로 규격)

1. **대사 포맷**: **`@캐릭터이름@ "대사 내용"`** (정체 불명 시 `@???@`). 탭 4 캐릭터의 **`별명`**에 단축 이름(`아야메` 등)을 등록하면 프로필 사진이 대사창에 자동 매칭됩니다.
2. **이미지 출력 공식 (폴더 경로 규격)**:
   ```text
   {{url}}[캐릭터접두사]/[캐릭터접두사]_[3자리코드]_[포즈명].webp
   ```
   - 예시: `{{url}}aya/aya_004_토라짐.webp`, `{{url}}yur/yur_054_캠퍼스_도서관.webp`
   - 반드시 대사 바로 윗줄에 1:1 직결 배치하며, 1턴당 감정·자세 변화에 맞춰 **2~4회** 적극 호출합니다.

### 1.5. v3.0 문학적 서술 불변식 (`[계속하기]` · 70% 스포트라이트 · Show, Don't Tell)

1. **`U(플레이어) 사칭 절대 금지 (No Auto-play)`**: 플레이어의 대사·속마음·행동·신체 반응을 AI가 절대 대신 서술하지 않습니다.
2. **Show, Don't Tell & 완급(Contrast)**: "독점욕의 수위를 짐작할 수 있었다" 같은 건조한 심리 해설 문장을 금지하고 시선·손끝 떨림·호흡·공간 소리로 드러냅니다. 고호감도(Phase 3~4)에서도 매 턴 과열을 반복하지 않고 일상 장난·투닥거림과 밀착 순간의 온도 차이를 살립니다.
3. **유연한 웹소설 장면 호흡(800~1,200자) & `[계속하기]` 대응**:
   - 구형 단문 하드스탑(`350~500자`)을 폐기하고, 웹소설 한 장면 분량인 **800~1,200자 내외**로 유연하게 전개한 뒤 결정적 비트(Beat)에서 종료합니다. (하단 JSX 상태창이 잘리지 않도록 여유 확보, 시작 설정 히든 프롬프트도 동일 기준 통일)
   - 유저가 침묵하거나 **`[계속하기]`**를 누르면 대치 상황을 제자리 반복하지 말고 **캐릭터 쪽에서 먼저 한 발 다가가거나 자연스럽게 상황을 전환**합니다.
4. **주 화자 70% 스포트라이트 (최대 3인 · 출석 체크 금지)**:
   - 기본은 주 화자 1인 1:1 집중입니다. 다인 씬에서도 최대 3인까지만 허용하며 주 화자 1명이 대사·묘사의 약 70%를 이끌고 나머지 인원은 추임새 1~2마디 후 자연 퇴장시킵니다. 방 안 전원이 돌아가며 말하는 출석 체크식 발화를 금지합니다.
5. **선물·인벤토리 설정 정합성 & Prefix 백업 테이블**:
   - 각 캐릭터의 선호 선물(`CHAR_META.fav`, `[캐릭터]`, `[프롬프트]`, `Board` 보상)은 **본인의 직업·종교·판매/수호 물품과 충돌하지 않는 상보적 품목**으로 설계합니다 *(예: 중화풍 주인 `시아→고급 녹차`, 무녀 `아오이→수제 화과자`, 수녀 `세라→들꽃 꽃다발`, 체육부 `유키→시원한 이온음료`)*.
   - 메인 프롬프트 `[에셋 인덱스]` 바로 윗줄에는 키워드 미매칭 턴 오출력을 막는 **1줄 요약 `[캐릭터 접두사(prefix)]` 테이블**을 반드시 배치합니다.

### 1.6. 8~12대 유기적 변수 & 동적 확장(`CHAR_META`) 아키텍처

핵심 게임 루프의 LLM 인지 부하를 막기 위해 **기본 8변수**를 코어로 삼되, 자유 거점 샌드박스·의뢰·선물 루프에서는 **확장 4변수**를 더한 **8~12대 변수 체계**를 표준으로 삼습니다. 모든 `0~100` 수치는 프롬프트에 **`%` 기호 없이 순수 정수만 기입**합니다.

| 구분 | 변수 Key | 초기값 예시 | 역할 |
| :---: | :--- | :---: | :--- |
| **코어 8종** | `turn` / `time` / `location` | `1` / `낮` / `마을 입구` | 누적 턴, 시간대, 직관적 한글 거점명 |
| **코어 8종** | `char_name` / `affection` | `아야메` / `35` | 현재 주 화자 및 호감도 (**0~100 정수**, `%` 생략) |
| **코어 8종** | `submissiveness`(또는 `stress`) / `tension` | `15` / `15` | 굴복·피로 지수 / 열기·질투 텐션 (**`70+` 난입·고조**) |
| **동적 DB** | `roster_stats` | `이름:호감/보조,...` | **전원 개별 영구 기록장** (고정 인원수 없이 신규 인물 자동 추가) |
| **확장 4종** | `day` / `weather` | `1일차 (월)` / `맑음` | 요일별 축제·배경·복장(`attire`) 분기 *(샌드박스 선택 확장)* |
| **확장 4종** | `trust` / `items` | `20` / `품목:수량,...` | 평판·비밀 거점 해금(`50+`) 및 선물 인벤토리 *(전역변수 전용)* |

* **고정 인원수 탈피 불변식**: 프롬프트·설정집·HTML·JSX 어디에도 "6인방", "13명 전원" 같은 고정 인원수를 하드코딩하지 않으며, JSX 상단 **`CHAR_META` 1줄 추가** 및 `roster_stats` 동적 파싱으로 신규 캐릭터가 즉시 합류합니다.

### 1.7. 탈 얀데레 `Status` · `Talk` · `Board` & `ambient` 풍경 바 규칙

1. **매 턴 맨 마지막 줄 고정 — `[@id=Status|...]`** *(수치는 `%` 제외 정수, 평소 70~80%는 `dm_from=없음`)*:
   ```text
   [@id=Status|turn=[정수]|day=[N일차(요일)]|time=[아침/낮/저녁/밤]|weather=[날씨]|location=[한글장소명]|char_name=[주화자]|affection=[정수]|submissiveness=[정수]|tension=[정수]|trust=[정수]|roster_stats=[이름:호감/보조,...]|items=[품목:수량,...]|ambient=[배경풍경1줄]|dm_from=[발신자또는없음]|dm_preview=[미리보기또는빈값]|attire=[복장상태]|reaction=[속마음]]
   ```
   - **탈 얀데레 1:1 DM 쿨타임 규칙**: 매 턴 상단에 톡 알림을 띄우지 않습니다. 평소 턴의 **70~80%는 `dm_from=없음|dm_preview=`로 비워 두고 `ambient`에 고요한 풍경·소리 1줄**만 출력합니다. 개인톡은 **최소 3~4턴 쿨타임** 후 시간대 전환·헤어진 직후·이벤트 후에만 1건 도착시키며, **[일상·나눔 / 가벼운 부탁·초대 / 수줍은 여운]** 위주로 작성합니다. 질투·독점형 톡은 **`affection >= 75` AND `tension >= 75`일 때만 예외 허용**합니다.
   - **1:1 개인톡 완벽 격리 3대 불변식 (메인 프롬프트 + 로어북 이중 방어)**:
     1. **정보 비대칭(텔레파시 금지)**: 개인톡(`Talk`)은 {{user}}와 발신자 둘만의 비밀입니다. 유저가 화면을 보여주거나 직접 말하기 전까지 현장 타인의 대사·지문·`Status.reaction`에 톡 발신자/내용을 절대 언급하지 않습니다. (외적으로 폰을 보는 모습만 인지)
     2. **본문 중복 발화 & 원격 유령 등장 금지**: 1:1 톡 메시지는 오직 `[@id=Talk]` `log=` 안에서만 출력하며, 현장에 없는 톡 상대를 본문 `@이름@ "..."`으로 재발화하거나 원격 이미지를 띄우지 않습니다.
     3. **유저 답장(`나:...`) 대필 금지 & 배지 초기화**: 유저가 직접 `[1:1 톡 답장]`·`[1:1 톡 선톡]`으로 보낸 원문만 `log=`의 `나:...`로 기록하며, **유저가 도착한 톡을 확인/답장한 턴에는 반드시 `dm_from=없음|dm_preview=`로 배지를 비웁니다.**
2. **조건부 1:1 개인톡 — `[@id=Talk|...]`** *(하단 답장 입력창 상시 오픈 · 헤더 우측 `[📴 덮기]`)*:
   ```text
   [@id=Talk|room=[상대이름]|time=[HH:MM]|log=[상대:내용;;나:내답장;;상대:후속답장]]
   ```
   - `Status` 알림 배너에서 **`[💬 열기]` 클릭 시 AI 턴을 쓰지 않고 인라인 답장창을 먼저 펼쳐 답장**하며, `[@id=Talk]` 위젯은 유저의 직접 `[1:1 톡 답장]`/`[1:1 톡 선톡]` 턴에만 `Status` 바로 윗줄에 출력합니다 (`[톡 종료]` 시 중단).
3. **조건부 의뢰·공지 알림판 — `[@id=Board|...]`** *(호출 시 출력 강제)*:
   ```text
   [@id=Board|day=[N일차(요일)]|weather=[날씨]|notice=[오늘의공지1줄]|q1=[인물:의뢰제목:장소:보상]|q2=[...]|q3=[...]]
   ```
   - 새 아침, 거점 방문, 유저의 `[알림판/민원판 확인]` 호출 시 **서술만 하고 넘기지 말고 반드시 `Status` 바로 윗줄에 `[@id=Board|...]`를 출력**합니다.

### 1.8. 스토리 유도형 3대 선택지 & 실전 검증 코어 불변식

매 턴 본문 직후(상태창 윗줄)에 **`[💡 당신의 선택지]`** 3종(① 스토리 추진/거점 이동 ② 감정 심화/밀착 ③ 케어/완급 조절)을 고정 출력합니다.

1. **무제한 순수 턴 누적 (`turn=1, 2, 3...`) & 유연 호흡(`800~1,200자`)**
2. **주 화자 70% 스포트라이트 (일상 1:1 집중, 다인 씬 최대 3인 · 출석 체크 금지)**
3. **8~12대 변수 (`%` 제외 정수) + `roster_stats` 동적 인원 확장 (`CHAR_META`)**
4. **`U(플레이어) 사칭 절대 금지` + `[계속하기]` 능동 전환**
5. **Show, Don't Tell (외적 감각 묘사 & 고호감도 온도 차/완급 유지)**
6. **`@캐릭터@ "대사"` + 폴더형 이미지 직결 (`{{url}}{prefix}/{prefix}_{code}.webp`) + 1줄 Prefix 백업**
7. **4단계 관계 Phase + 소프트 락 & 조르기 돌파 + 1회 튕기기 법칙**
8. **듀얼 트랙 이벤트 + 선택형 D20 Fail-Forward (자연·일상 16종 `EVENT_POOL`)**
9. **히든 프롬프트(2,000자 독립 버퍼) 관계 격리 + 고호감도 프롤로그 1인 집중**
10. **상보적 선호 선물 정합성 (직업·종교·자체 상품 충돌 금지) & `items=` 누락 점검**
11. **1:1 개인톡 비밀 격리 3불변식 (텔레파시·원격발화·`나:` 대필 금지 & `dm_from=없음` 초기화)**
12. **`Status` 인라인 DM(`isDmOpen`) + 상시 입력창 `Talk` + `Board` 강제 출력**
13. **JSX 공식 규격 (`React.` 접두 · 리터럴 `setReturnValue` 200자 · 클릭 전용 · `fillInput`/`sendMessage` 분리 · `light-dark()`)**
14. **CommonMark 0칸 정렬 & `<details>` / `[NEW RESIDENTS]` 확장형 인트로 HTML**

## PART 4: [탭 5: 에셋] 공식 JSX 규격 · 3종 위젯 & D20 돌발 이벤트 엔진

### 4.1. 공식 JSX 샌드박스 6대 불변 규격 (Official Sandbox Rules)

1. **`React.` 접두 훅 강제**: 모든 훅은 반드시 `React.useState`처럼 `React.` 접두를 붙입니다. (단독 `useState` 금지)
2. **반환변수 리터럴 키 & 200자 상한**: `setReturnValue('tone', ...)`, `'event'`, `'gift'`, `'dm_reply'`, `'quest'`처럼 정적 파서가 인식하는 **문자열 리터럴 키로 직접 호출**하며(`forEach` 동적 루프 금지), 1턴 총 반환변수 합계(이름+값)를 **200자 이내**로 제한합니다.
3. **전역변수 분리**: `roster_stats`, `items` 같은 대용량 문자열은 `setReturnValue`가 아닌 `useTemplateValue`/`setTemplateValue` 전역변수로만 관리하며, 수치 파싱 시 `.replace(/[^0-9-]/g, "")`로 이중 `%`(`%%`) 버그를 원천 차단합니다.
4. **클릭 핸들러 전용 상태 변경**: `setTemplateValue`/`setReturnValue`는 컴포넌트 렌더 본문에서 절대 호출하지 않고, 실제 사용자 `onClick` 내부에서만 동기 호출합니다.
5. **실행(`sendMessage`) vs 입력 보조(`fillInput`) 분리**: 거점 이동·의뢰 수락·선물·톡 전송 등 시스템 액션은 **`sendMessage(text, false)`** 즉시 실행, 어프로치·케어 등 롤플레이 자유도가 필요한 버튼은 **`fillInput(text, false)`**로 입력창 초안만 채웁니다.
6. **테마·폴백·동적 확장**: `@media`/`class` 대신 `light-dark(라이트, 다크)` 또는 `var(--color-*)`를 쓰고, 상단 `CHAR_META` 1줄 확장·미등록 캐릭터 자동 인식·`failedUrls` 모노그램/이니셜 폴백을 구현합니다.

### 4.2. 모듈형 3종 JSX 위젯 & D20 ‘Fail-Forward’ `EVENT_POOL`

표준 청사진 소스는 [`GENIT_MULTI_THEME_TEMPLATE_v3.0.md`](genit/GENIT_MULTI_THEME_TEMPLATE_v3.0.md) · [`oto_v3_0.md`](genit/oto_v3_0.md)(기존 v2.2 레퍼런스는 [`캠퍼스_완성본`](genit/%EC%BA%A0%ED%8D%BC%EC%8A%A4_%EC%A0%A0%EC%9E%87_%EC%BA%90%EB%A6%AD%ED%84%B0_%EC%B1%84%ED%8C%85_v2.2_%EC%99%84%EC%84%B1%EB%B3%B8.md))을 참조합니다:

1. **상시 `Status` (4탭 컴팩트 HUD + 인라인 DM 답장창)**: `[📊 상태]` · `[📍 이동(동적 인원수)]` · `[🎁 선물]` · `[💌 톡·민원]` 4탭 + 고요한 `ambient` 풍경 바 + `[톤 3종 토글]` + `[🎲 돌발 이벤트 굴리기]`/`[⚡ 발동]`.
   - **인라인 1:1 DM 답장창**: 알림 배너(`hasDm`)에서 `[💬 열기]` 클릭 시 AI에게 즉시 턴을 넘기지 않고 `React.useState`(`isDmOpen`, `dmReplyDraft`)로 **배너 아래에 발신자 프로필·메시지·직접 답장 입력창·`[전송]` 버튼을 인라인으로 펼칩니다.** `[전송]` 클릭 시에만 `setReturnValue('dm_reply', ...)`(리터럴 키, 40자 슬라이스) + `sendMessage('[1:1 톡 답장 | 대상] 내용', false)`를 동기 실행합니다.
   - **D20 Fail-Forward 공식**: `roll(1~20) + floor(호감도 / 25)` ➔ `18+ 💥특급` · `11~17 ✨성공` · `5~10 😳아슬아슬` · `1~4 😈스릴역전` (낮은 눈금에도 호감도 페널티 금지, `setReturnValue('event', '합계|등급|상황')`).
   - **`EVENT_POOL` 16종 작성 원칙**: "속마음 고백", "억지 스킨십" 같은 작위적 이벤트를 배제하고 소나기·돌풍·정전·확성기 방송·발목 삐끗 등 **세계관 날씨·시설·일상에서 자연 발생하는 물리적 해프닝**만 수록합니다.
2. **조건부 `Talk` (상시 입력 바 + 헤더 우측 `[📴 덮기]`)**: `[💬 답장하기]` 토글을 제거하고 **하단 답장 입력창을 상시 오픈** 상태로 두며, `[📴 덮기]` 버튼은 상단 헤더 우측으로 슬림화합니다. `dm_reply` 반환변수 + `sendMessage(..., false)`로 1클릭 답장합니다.
3. **조건부 `Board` (의뢰·공지 알림판)**: 새 아침·거점 방문·확인 버튼 클릭 시 일일 의뢰 3건을 **반드시 `Status` 윗줄에 출력**하고, `[✅ 수락·이동]` 시 `quest` 반환변수 + `sendMessage(..., false)`로 즉시 이동합니다.

## 1. 프로젝트 계보 및 목적

플에파(PLEPA)는 이전 세대 프로젝트(키로: SDXL WebUI Forge 기반)의 80종 캐릭터 챗봇 에셋 체계와 젠잇(Gen-IT) 연동 규격을 계승하면서, 세계 최고 수준의 이미지 생성 모델인 **FLUX.1 [dev]**와 **ComfyUI 로컬 API**를 결합해 완전 자율형 고품질 배치 파이프라인으로 구축된 독립 신규 리포지토리입니다.

---

## 2. 하드웨어 환경 및 아키텍처 의사결정 기록 (ADR)

### 2.1 개발자(사용자) 하드웨어 스펙
- **GPU**: NVIDIA GeForce RTX 4060 Ti **8GB VRAM**
- **RAM**: DDR4 **48GB (3200MHz, 4슬롯 풀뱅크)**
- **CPU**: Intel Core i5-13600KF (14코어 / 20스레드)
- **저장장치**: NVMe 고속 SSD

### 2.2 핵심 아키텍처 결정 사항
1. **ComfyUI 로컬 API 채택**:
   - Forge 백엔드 대비 ComfyUI는 노드 기반 비동기 API 제어가 용이하며, 자동 얼굴 보정(Face Detailer), 초해상도 AI 업스케일러(4x-UltraSharp), GGUF 모델 로더 노드를 단일 파이프라인으로 유연하게 결합 가능.
2. **GGUF Q6_K 양자화 규격 채택**:
   - RTX 4060 Ti의 8GB VRAM 한계를 극복하기 위해 GGUF 포맷 채택.
   - 방대한 48GB 시스템 RAM을 모델 오프로딩 버퍼로 활용하여, 12B 모델임에도 VRAM 누수 없이 60장 연속 배치를 안정적으로 완주.
   - Q8_0 대비 생성 속도를 15~20% 단축(장당 약 79~88초)하면서도 순정 FP16과 구별이 불가능한 최상의 디테일을 유지.

## 4. 4대 시스템 불변식 (Invariants)

1. **Danbooru 쉼표 태그 및 `BREAK` 문법 철폐**:
   - T5-XXL 텍스트 인코더에 최적화된 완전한 영문 서술형 자연어 문장 사용.
2. **관심사의 철저한 분리 (Separation of Concerns)**:
   - 프롬프트 데이터는 `flux_pose_database.json`, 캐릭터 외형은 `projects/[roster]/characters/`, 실행 로직은 `plepa_engine/`에 철저히 격리.
3. **스마트 의상 격리 (Nude Exclusion)**:
   - 탈의 포즈 및 H씬(40~59, 140~159)에서는 캐릭터의 평상시 의상 서술어를 원천 배제.
4. **다중 PC 이식성(Portability) 보장**:
   - 코드 내 절대 경로 하드코딩 금지. 환경 변수(`COMFYUI_HOST`) 및 상대 경로(`PROJECTS_DIR`)를 통해 어떤 PC에서 클론하더라도 즉시 실행 가능.

## 캐릭터 default_mode 시스템 (키로 호환)

### 개요

**default_mode**는 키로(Kiro) 프로젝트의 `roster.py` 로직을 플에파에 이식한 기능으로, 캐릭터별로 선호하는 생성 엔진을 JSON에 명시하여 **CLI나 GUI에서 자동으로 적용**되도록 합니다.

### 지원 엔진 및 별칭

플에파는 **듀얼 엔진** 구조를 채택하고 있으며, 다음 두 가지 주 엔진과 여러 별칭을 지원합니다:

| 엔진명 | 별칭 | 실제 해석값 | 특징 |
|--------|------|-------------|------|
| `sdxl` | `fast`, `f` | `sdxl` | Unholy Desire Mix 등 고속 2D 애니 체크포인트, IP-Adapter 지원 |
| `flux` | `quality`, `q` | `flux` | FLUX.1 [dev] GGUF, 고품질 자연어 프롬프트, LoRA 지원 |
| (빈칸) | - | `DEFAULT_ENGINE` | 환경변수 `PLEPA_DEFAULT_ENGINE` 또는 `sdxl` |

### 캐릭터 JSON 설정 예시

```json
{
  "prefix": "sample",
  "name": "샘플 캐릭터",
  "gender": "female",
  "default_mode": "flux",
  "appearance": {
    "face_and_hair": "...",
    "physique": "...",
    "outfit": "..."
  }
}
```

- `"default_mode": null` 또는 생략: 시스템 기본값 사용
- `"default_mode": "flux"` 또는 `"quality"`: FLUX 엔진 우선
- `"default_mode": "sdxl"` 또는 `"fast"`: SDXL 체크포인트 우선

### 자동 적용 규칙

1. **단일 캐릭터 생성 시**: 해당 캐릭터의 `default_mode`가 CLI `--engine` 플래그보다 우선 적용됩니다.
   ```bash
   python flux_batch_generator.py -c sample_character -p 000..019 --engine sdxl
   # 출력: [INFO] 캐릭터 'sample'의 default_mode 'flux' → 'flux' 자동 적용
   ```

2. **다중 캐릭터 배치 시**: 사용자가 명시한 `--engine` 값을 사용합니다.
   ```bash
   python flux_batch_generator.py -c oes,sce,ykn -p 038,039 --engine sdxl
   # 모든 캐릭터에 sdxl 적용 (default_mode 무시)
   ```

3. **GUI에서**: 캐릭터 관리 페이지에서 default_mode를 설정하면, 생성 페이지에서 해당 캐릭터 선택 시 엔진 셀렉터가 자동 변경됩니다.

### GUI 사용법

#### 캐릭터 페이지에서 default_mode 설정

1. 좌측 사이드바에서 캐릭터 선택
2. 우측 폼에서 **"⚡ 기본 엔진 모드 (default_mode)"** 드롭다운 확인
3. 원하는 엔진 선택 (빈칸, sdxl, flux, fast, quality 중 택 1)
4. **저장** 버튼 클릭

#### 생성 페이지에서 자동 반영 확인

1. 배치 생성 페이지로 이동
2. default_mode가 설정된 캐릭터 **1명만** 선택 시, 엔진 셀렉터가 자동으로 해당 모드로 변경됨
3. 여러 캐릭터 선택 시, 사용자가 수동으로 엔진 선택

### 코드 구조

- **`plepa_engine/config.py`**: `_DEFAULT_MODE_MAP`, `resolve_default_mode()` 함수
- **`plepa_engine/models.py`**: `CharacterConfig.default_mode` 필드
- **`plepa_engine/services/schemas.py`**: `CharacterSchema.default_mode` Pydantic 검증
- **`plepa_engine/services/generation_service.py`**: `run_batch()` 시작 부분에서 단일 캐릭터 자동 해석
- **`plepa_gui/pages/characters.py`**: default_mode UI 입력 및 저장 로직

### 검증 및 오류 처리

- 유효하지 않은 값 입력 시 `ValueError` 발생
- GUI에서는 드롭다운으로 제한하여 입력 오류 방지
- CLI에서는 invalid 값 입력 시 경고 출력 후 시스템 기본값 폴백

- **체크포인트**: Flatbread - IL - v6.0 (`flatbreadILV60.safetensors`)

### 듀얼 캐릭터 JSON 시스템

각 캐릭터 JSON에 `sdxl_positive`(착의용)와 `sdxl_nude_positive`(탈의용) 두 개의 프롬프트를 보유한다. 엔진이 포즈 번호를 보고 자동으로 선택한다:

- **000~037번**: `sdxl_positive` 사용 — 의상 태그 포함된 일반 착의 상태
- **038~159번**: `sdxl_nude_positive` 사용 — 신체/얼굴 태그만, 의상 태그 전혀 없음

이 시스템 덕분에 캐릭터 JSON 하나로 착의/탈의 전 범위를 커버하며, 포즈마다 수동으로 의상을 제거할 필요가 없다.

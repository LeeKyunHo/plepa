## 1. 프로젝트 계보 및 목적

플에파(PLEPA)는 이전 세대 프로젝트(키로: SDXL WebUI Forge 기반)의 80종 캐릭터 챗봇 에셋 체계와 젠잇(Gen-IT) 연동 규격을 계승하면서, 세계 최고 수준의 이미지 생성 모델인 **FLUX.1 [dev]**와 **ComfyUI 로컬 API**를 결합해 완전 자율형 고품질 배치 파이프라인으로 구축된 독립 신규 리포지토리입니다.

---

## 2. 하드웨어 환경 및 아키텍처 의사결정 기록 (ADR)

### 2.1 개발자(사용자) 하드웨어 스펙
- **GPU**: NVIDIA GeForce RTX 4060 Ti **8GB VRAM**
- **RAM**: DDR4 **48GB (3200MHz, 4슬롯 풀뱅크)**
- **CPU**: Intel Core i5-13600KF (14코어 / 20스레드)
- **저장장치**: NVMe 고속 SSD

### 2.2 핵심 아키텍처 결정 사항
1. **ComfyUI 로컬 API 채택**:
   - Forge 백엔드 대비 ComfyUI는 노드 기반 비동기 API 제어가 용이하며, 자동 얼굴 보정(Face Detailer), 초해상도 AI 업스케일러(4x-UltraSharp), GGUF 모델 로더 노드를 단일 파이프라인으로 유연하게 결합 가능.
2. **GGUF Q6_K 양자화 규격 채택**:
   - RTX 4060 Ti의 8GB VRAM 한계를 극복하기 위해 GGUF 포맷 채택.
   - 방대한 48GB 시스템 RAM을 모델 오프로딩 버퍼로 활용하여, 12B 모델임에도 VRAM 누수 없이 60장 연속 배치를 안정적으로 완주.
   - Q8_0 대비 생성 속도를 15~20% 단축(장당 약 79~88초)하면서도 순정 FP16과 구별이 불가능한 최상의 디테일을 유지.

## 4. 4대 시스템 불변식 (Invariants)

1. **Danbooru 쉼표 태그 및 `BREAK` 문법 철폐**:
   - T5-XXL 텍스트 인코더에 최적화된 완전한 영문 서술형 자연어 문장 사용.
2. **관심사의 철저한 분리 (Separation of Concerns)**:
   - 프롬프트 데이터는 `flux_pose_database.json`, 캐릭터 외형은 `projects/[roster]/characters/`, 실행 로직은 `plepa_engine/`에 철저히 격리.
3. **스마트 의상 격리 (Nude Exclusion)**:
   - 탈의 포즈 및 H씬(40~59, 140~159)에서는 캐릭터의 평상시 의상 서술어를 원천 배제.
4. **다중 PC 이식성(Portability) 보장**:
   - 코드 내 절대 경로 하드코딩 금지. 환경 변수(`COMFYUI_HOST`) 및 상대 경로(`PROJECTS_DIR`)를 통해 어떤 PC에서 클론하더라도 즉시 실행 가능.

## ⚠️ 주의사항

### 동기화 전 확인사항

1. **키로-플에파 구조 차이**
   - 포즈 코드 형식: 문자열 `"065"` vs 정수?
   - 섹션명: `h_scenes` vs 다른 이름?
   - 필드명: `label`, `description`, `prompt` 동일한지?

2. **키로 독자적 수정사항**
   - 키로에만 있는 커스텀 포즈는 덮어쓰지 않도록 주의
   - 키로의 독자적인 프롬프트 개선사항 확인

3. **프롬프트 스타일 차이**
   - SDXL vs 다른 모델의 프롬프트 문법 차이
   - 가중치 표기법: `(tag:1.35)` vs `{tag}` vs `[tag]`

### 덮어쓰면 안되는 것들

- ❌ 키로에만 있는 커스텀 포즈
- ❌ 키로의 독자적인 프롬프트 최적화
- ❌ 키로 캐릭터 전용 설정
- ❌ 키로 로스터 전용 pose_overrides

## 📞 문제 해결

### Q1. "KeyError: 'h_scenes'" 오류

**원인**: 키로와 플에파의 섹션명이 다름

**해결**:
```python
# sync_poses_to_kiro.py 수정
section = "h_scenes"  # 또는 키로의 실제 섹션명으로 변경
```

### Q2. 백업이 생성되지 않음

**원인**: 키로 포즈 DB 경로를 찾지 못함

**해결**:
```bash
# 키로 포즈 DB 위치 확인
ls D:\kiro\data\*.json
ls D:\kiro\*.json

# 스크립트에 직접 경로 지정
```

### Q3. 동기화 후 테스트 생성 실패

**원인**: 프롬프트 형식 차이

**해결**:
```bash
# 백업으로 복원
cp [backup_path] [kiro_db_path]

# 수동으로 하나씩 확인하며 적용
```

### Q4. 차이점 리포트가 너무 많음

**원인**: 키로가 독자적으로 많은 수정을 했을 가능성

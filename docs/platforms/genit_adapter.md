## 2. 이미지 · 에셋 · 경로 규격

1. **본문 채팅 이미지**:
   ```text
   {{url}}[캐릭터접두사]/[캐릭터접두사]_[3자리코드]_[포즈명].webp
   ```
2. **탭 1 `[설명]` 인트로 이미지**:
   - `{{url}}` 미지원 → `[이미지 업로드]` 후 `{{파일명.webp}}` 사용.
   - CommonMark 파싱 깨짐 방지를 위해 **매크로 위·아래 빈 줄 1줄씩 격리** + **HTML 선행 공백 0칸 정렬**.
3. **탭 5 `[에셋]` JSX 내부 이미지**:
   - `{{url}}` 미지원 → 채팅 본문 정상 이미지에서 추출한 CloudFront `ASSET_BASE_URL` 상수 + `encodeURIComponent(...)` 사용.
4. **에셋 해상도 통일**:
   - 로컬 생성(`832×1216`) 후 `plepa_gui` **`Genit 내보내기`**에서 **`1024×1536`** 중앙 크롭 일괄 패키징(`dist/genit/{roster}/{prefix}/`).

## 3. 상태창 & 양방향 메신저 구현

- **상태창 (`Status`)**: 매 턴 마지막 줄에 고정 출력:
  ```text
  [@id=Status|turn=[턴]|time=[낮/밤]|location=[한글장소명]|char_name=[메인히로인]|prog=[진척도]|d_day=[남은일수]|affection=[호감도]|stress=[피로및질투텐션]|roster_stats=[이름:호감/텐션,...]|line_msg=[짧은메신저알림1줄]|reaction=[외적반응또는속마음]]
  ```
- **메신저 (`Line`)**: 질투 인터셉트(`stress 70+`), 심야 톡, 유저 선톡/답장 시에만 상태창 바로 윗줄에 출력:
  ```text
  [@id=Line|room=[방이름]|time=[HH:MM]|log=[화자:내용;;나:내답장;;화자:후속답장]]
  ```

# 🏛️ 캐릭터 채팅 공통 코어 제작 헌법 (Universal Core Spec)

> **기준 출처**: [`docs/젠잇_캐릭터채팅_제작법.md`](../%EC%A0%A0%EC%9E%87_%EC%BA%90%EB%A6%AD%ED%84%B0%EC%B1%84%ED%8C%85_%EC%A0%9C%EC%9E%91%EB%B2%95.md) (v2.2 실전 검증본)  
> **원칙**: 이 문서에 정의된 규칙은 **특정 플랫폼 문법(`{{url}}`, JSX 등)과 무관하게 모든 캐릭터 채팅 플랫폼에서 동일하게 유지되어야 하는 작품 설계의 뼈대**입니다. 플랫폼별 문법 변환은 각 `*_adapter.md`에서 처리합니다.

## 1. 문학적 서술 3대 불변식 (Narrative Invariants)

1. **`U`(플레이어) 사칭 절대 금지**
   - AI는 플레이어의 대사, 속마음, 자발적 행동, 신체 반응을 절대 대신 서술하지 않습니다. 오직 플레이어 입력의 물리적 결과와 상대 캐릭터의 반응만 묘사합니다.
2. **빙산 이론 (외적 감각 묘사)**
   - `~라고 생각했다` 식의 직접적인 내면 독백 설명을 배제하고, 시선 회피, 손끝 떨림, 귀 끝 홍조, 호흡 변화, 옷자락 잡기 등 **관찰 가능한 외적 감각**으로 심리를 드러냅니다.
3. **1턴 1인 주 화자 포커스 & 구어체 원칙**
   - 1턴 분량은 **600~800자** 기준, 시각적 리듬은 **`[상황 이미지 2~4회] > [대사] > [감각 서술]`** 순서를 유지합니다.
   - 번역투·문어체를 배제하고 생동감 있는 구어체를 사용하며, 일상 씬은 1:1 독점에 집중하고 다인 개입은 `[질투 인터셉트]`·`[합숙/이벤트]` 시에만 허용합니다.

## 2. 대사 및 이미지 직결 공통 규격

1. **화자 표기 표준**: `@캐릭터이름@ "대사 내용"` (정체 불명 시 `@???@`).
   - 플랫폼에 화자 별명/프로필 매칭 기능이 있으면 단축 이름(`아야메` 등)을 반드시 등록하고, 없으면 텍스트 화자 태그로 일관 유지합니다.
2. **이미지 배치 원칙**:
   - 대사 바로 윗줄에 **1:1 직결** 배치하며, 1턴당 감정·자세 변화에 맞춰 **2~4회** 호출합니다.
   - **실존 포즈 계약 (Zero-Hallucination)**: 포즈 코드와 서픽스(`[접두사]_[3자리코드]_[포즈명]`)는 반드시 해당 로스터의 실존 에셋 목록(`POSE_MAPPING.md` 또는 `projects/{roster}/genit_map.json`)에 존재하는 것만 사용합니다.
   - 실제 이미지 출력 태그(`{{url}}...`, `![img](...)`, `<img ...>`)는 **각 플랫폼 어댑터의 변환 규칙**을 따릅니다.

## 3. 4대 핵심 파라미터 & 8대 통일 변수 데이터 모델

LLM의 계산 인지 부하를 막기 위해 **핵심 게임 루프는 4대 파라미터**로 유지하고, 다중 히로인 거점 이동·시간 경과를 위해 **보조 4변수**를 결합한 8대 변수를 표준 데이터 모델로 사용합니다.

| 구분 | 논리 Key | 초기값(예시) | 역할 및 상태 전이 규칙 |
| :--- | :--- | :---: | :--- |
| **공통 공유** | `prog` | `0` | 메인 퀘스트 진척도 (`0~100%`, `25%` 단위 마일스톤) |
| **공통 공유** | `d_day` | `14` | 마감 카운트다운 (`밤 ➔ 다음 날 아침` 전환 시 `-1`) |
| **공통 공유** | `turn` | `1` | 무제한 순수 누적 턴 수 (`1, 2, 3...`) |
| **공통 공유** | `time` | `낮` | 시간대 분기 (`낮` 주간 해프닝 1~3 / `밤` 심야 해프닝 4~6) |
| **공통 공유** | `location` | `도서관 열람실` | 직관적 한글 키워드형 거점명 (복잡한 건물·호실 수식어 금지) |
| **개별 포커스** | `affection` | `35` | 현재 대화 중인 히로인의 호감도 (`0~100`, Phase 1~4) |
| **개별 포커스** | `stress` | `15` | 피로도 및 라이벌 질투 텐션 (`50+` 케어 찬스 / **`70+` 질투 인터셉트**) |
| **개별 DB** | `roster_stats` | `이름:35/15,...` | **전원 `[이름:호감/텐션]` 영구 기록장** (거점 이동 시 스탯 보존) |

> [!NOTE]
> 플랫폼이 **전역 변수/상태창 위젯을 지원하지 않는 경우**에도, 이 8대 필드는 어댑터에서 정의하는 **텍스트 상태창 블록(예: 마크다운 인용구 또는 코드블록)**으로 동일하게 매 턴 말미에 출력하여 LLM 기억 연속성을 유지합니다.

## 4. 핵심 게임 루프 & 서사 엔진 규칙

1. **4단계 거대 서사 아크 (Macro Story Flow)**
   - **Ch.1 착수 (`0~25%`)**: 재회/초면, 목표 설정, 첫 일상 교류
   - **Ch.2 합숙 (`26~50%`)**: 중간 점검, 심야 밀착/합숙 이벤트
   - **Ch.3 위기 (`51~75%`)**: 리허설/갈등 고조, 밀폐 공간 첫 깊은 교류
   - **Ch.4 결말 (`76~100%`)**: 최종 목표 달성, 고백 및 에필로그
2. **듀얼 트랙 이벤트 (마일스톤 + 주사위 순환)**
   - **마일스톤**: `prog` `25% / 50% / 75% / 100%` 도달 시 핵심 사건 자동 발동.
   - **주사위 해프닝**: `낮(1~3)` / `밤(4~6)` 분기. 직전과 동일한 번호가 나오면 **`+1` 순환 슬라이딩**으로 중복 방지.
3. **4단계 관계 Phase & 소프트 락**
   - `Phase 1 (탐색)` ➔ `Phase 2 (친밀)` ➔ `Phase 3 (연인/밀착)` ➔ `Phase 4 (완전 함락)`.
   - 단계를 건너뛰는 급발진 요구 시 **소프트 락(1회 튕기기 + 조르기 돌파)**으로 긴장감 유지.
4. **라이벌 질투 인터셉트 & 6인 자유 거점 이동**
   - `stress 50~69`: 케어 찬스(유저가 다독여 텐션 완화 가능).
   - `stress 70+`: **질투 인터셉트** 발동 (타 히로인의 메신저 급습 또는 현장 난입).
   - 6인 전원 `roster_stats`로 개별 수치를 보존하므로 언제든 거점을 옮겨도 관계가 초기화되지 않음.
5. **스토리 유도형 3대 선택지**
   - 매 턴 본문 직후(상태창 윗줄)에 **① 스토리 추진/거점 이동 ② 감정 심화/밀착 ③ 질투 케어/완급 조절** 3종 선택지를 고정 출력하여 유저 입력 피로를 줄임.

## 5. 루트 격리, 키워드, 유저/AI 필드 이원화 원칙

1. **루트별 관계성 최우선 격리**:
   - 시작 루트(예: 소꿉친구 루트 vs 초면 루트) 간 과거사 기억 오염을 막기 위해, 캐릭터 공통 프로필에는 `[불변식] 관계는 시작 루트 설정을 최우선으로 따른다`를 명시하고 타임라인(예: 재회 연수) 모순을 사전 검수합니다.
2. **로어북/캐릭터 트리거 비중복 원칙**:
   - 여러 캐릭터·설정집이 동시에 오작동하지 않도록 `동기`, `선배` 같은 **공통 명사 키워드 중복을 절대 금지**하고 고유 이름·거점·전용 속성만 키워드로 배정합니다.
3. **유저 열람 필드 vs AI 전용 필드 이원화**:
   - **유저 열람용** (작품 소개, 가이드, 프롤로그, 선택지, 설정집 설명): 가독성과 시각적 매력 중심 작성.
   - **AI 전용 비공개** (시스템/메인/캐릭터/로어북 프롬프트): 장식용 마크다운(`**`, `###`, `---`)과 공손체를 배제하고 `[섹션 태그] + - 개조식 명령` 평문으로 압축해 지침 이행률과 토큰 효율을 극대화합니다.

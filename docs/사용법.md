## 1. 개요 (Overview)

플에파(PLEPA: Flux Asset Pipeline)는 차세대 12B 파운데이션 모델인 **FLUX.1 [dev]**와 **ComfyUI 로컬 비동기 API**를 결합하여, 챗봇 및 비주얼 노벨용 80종 캐릭터 에셋을 고해상도로 일괄 자동 생성하는 최첨단 배치 생성 시스템입니다.

---

## 2. ⚡ 가장 많이 쓰는 명령어 (치트시트)

> [!IMPORTANT]
> 윈도우 환경에서 터미널 출력 버퍼링과 한글 잘림을 방지하기 위해 항상 **`python -u`** 옵션으로 실행하는 것을 권장합니다.

### 2.1 듀얼 엔진 선택 (FLUX ↔ SDXL)
플에파는 필요에 따라 **12B FLUX 서술형 자연어 모드**와 **SDXL 언홀리 9.0 쾌속 2D 셀화 모드**를 즉시 스위칭할 수 있습니다.

```bash
# [추천] SDXL 언홀리 9.0 쾌속 모드 (장당 약 14초, 60장 배치 약 14분 완료)
python -u flux_batch_generator.py -r don -c all -p all --engine sdxl

# FLUX.1 [dev] GGUF 기본 모드 (장당 약 80~190초, 12B 파운데이션 묘사력)
python -u flux_batch_generator.py -r don -c all -p all --engine flux
```

### 2.2 ComfyUI 특화 품질 보정 옵션
```bash
# 1. Face Detailer 얼굴 자동 초정밀 보정 (전신 샷에서도 눈/코/입 뭉개짐 자동 복구)
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --face-detailer

# 2. 4x AI 초고해상도 업스케일러 통합 (4x-UltraSharp로 2K/4K급 에셋 직결 출력)
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --upscale

# 3. 얼굴 보정 + 초고해상도 업스케일 동시 적용
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --face-detailer --upscale
```

### 2.3 원클릭 전체 일괄 생성
```bash
# don 프로젝트의 모든 캐릭터(6명)를 대상으로 80종 전체 에셋 일괄 생성 (SDXL 모드)
python -u flux_batch_generator.py -r don -c all -p all --engine sdxl

# don 프로젝트의 모든 캐릭터를 대상으로 000번(평상), 001번(미소)만 빠르게 일괄 생성
python -u flux_batch_generator.py -r don -c all -p 000,001 --engine sdxl
```

### 2.4 단일 캐릭터 생성
```bash
# 특정 캐릭터 전체 80종 생성 (약 18분 소요)
python -u flux_batch_generator.py -r don -c bjh -p all --engine sdxl

# 특정 캐릭터의 감정 씬(000~019) 20종만 생성 (약 4.5분 소요)
python -u flux_batch_generator.py -r don -c ksn -p emotions --engine sdxl

# 특정 캐릭터의 일상/포즈 씬(020~039) 20종만 생성
python -u flux_batch_generator.py -r don -c bjh -p poses --engine sdxl

# 특정 캐릭터의 H씬(040~059) 20종만 생성
python -u flux_batch_generator.py -r don -c bjh -p h_scenes --engine sdxl

# 특정 캐릭터의 오토코노코 씬(140~159) 20종만 생성
python -u flux_batch_generator.py -r don -c shn -p otokonoko --engine sdxl
```

### 2.5 다중 캐릭터 묶음 생성
```bash
# 쉼표로 원하는 캐릭터들만 묶어서 순차 실행
python -u flux_batch_generator.py -r don -c bjh,ksn,shn -p 000,001 --engine sdxl
```

### 2.6 기본 동작: 빈칸만 채우기 (기존 파일 자동 보존)
플에파는 **이미 생성된 파일이 있으면 0초 만에 자동으로 건너뛰고, 누락된 빈칸 파일만 채우는 것이 기본값(Default)**입니다.
따라서 별도의 옵션 없이 실행해도 기존에 잘 뽑힌 에셋이 실수로 지워지거나 덮어씌워지지 않습니다.

```bash
# 전체 실행 시 이미 있는 파일은 건너뛰고, 없는 파일만 알아서 채움
python -u flux_batch_generator.py -r don -c all -p all --engine sdxl
```

### 2.7 파일 교체: 특정 포즈 다시 뽑아서 덮어쓰기 (`--overwrite` / `-f`)
마음에 안 드는 특정 포즈를 다른 시드로 다시 뽑아 **기존 파일을 새로운 이미지로 교체(리롤)**하고 싶을 때는 `--overwrite` (또는 `-f`) 옵션을 붙입니다.

```bash
# bjh의 000번 평상 포즈를 다시 뽑아 기존 파일 덮어쓰기 (00 입력도 호환)
python -u flux_batch_generator.py -r don -c bjh -p 000 --engine sdxl --overwrite

# 단축 옵션 -f 사용
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl -f
```

### 2.8 특정 번호 대역 지정 (3자리 000~159 체계, 하위 호환 지원)
```bash
# 번호 범위 지정 (.. 연산자)
python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl

# 쉼표로 특정 번호만 콕 집어서 생성 (00, 0 등 1~2자리 입력도 3자리로 자동 매핑)
python -u flux_batch_generator.py -r don -c bjh -p 000,003,005,020 --engine sdxl
```

### 2.9 캐릭터 목록 확인 (`-l` / `--list`)
로스터 내에 등록된 모든 캐릭터의 ID, 성별, 지원 프로필 목록, 기본 의상 요약을 터미널에 한눈에 표로 출력합니다.
```bash
python -u flux_batch_generator.py -r don -l
```

### 2.10 캐릭터 다중 의상/프로필 스위칭 (`--profile`)
캐릭터 JSON 내 `profiles` (또는 `_profiles`)에 정의된 다양한 의상/헤어 세팅(예: `summer`, `maid`, `bunny`)으로 프롬프트를 즉시 전환합니다.
```bash
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --profile summer
```

### 2.11 즉석 배경 프롬프트 직접 주입 (`--bg`)
`background.json`을 직접 수정하지 않고도 터미널에서 즉석으로 감정 씬(000~019)의 배경을 원하는 문장으로 직접 덮어씁니다.
```bash
# 즉석 배경 주입 (지정 시 --bg-preset 보다 우선 적용)
python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg "luxury yacht deck, ocean sunset"
```

### 2.12 배경 프리셋 변경 (`--bg-preset`)
```bash
# projects/don/background.json 에 등록된 배경 키를 감정 씬(000~019)에 일괄 적용
python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg-preset penthouse_living
python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg-preset room
python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg-preset elevator
```

### 2.13 추가 네거티브 프롬프트 오버라이드 (`--custom_neg`)
SDXL 모드에서 기본 네거티브 외에 특정 상황에서 제외하고 싶은 태그를 터미널에서 즉시 결합합니다.
```bash
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --custom_neg "glasses, hat, jewelry"
```

### 2.14 IP-Adapter 참조 이미지 제어 (`--ref_image` / `--ref_weight` / `--no_ref`)
ComfyUI `IPAdapterUnifiedLoader` + `IPAdapterAdvanced` 노드를 파이프라인에 직결하여 캐릭터 외형/얼굴 일관성을 보장합니다.
- **기본 동작**: `projects/[로스터]/references/[캐릭터].webp` 자동 탐색 및 주입 (가중치 0.85 또는 캐릭터 JSON 설정값).
- **가중치 조절 (`--ref_weight`)**: 영향력을 0.0~1.0 사이로 세밀 조절 (예: 0.75).
- **수동 이미지 지정 (`--ref_image`)**: 원하는 외부 이미지를 레퍼런스로 직접 지정.
- **비활성화 (`--no_ref`)**: IP-Adapter를 끄고 순수 텍스트 프롬프트로만 생성.

```bash
# 1. 자동 레퍼런스 감지 (기본값)
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl

# 2. 가중치 세밀 조절
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --ref_weight 0.75

# 3. IP-Adapter 비활성화 (순수 프롬프트 모드)
python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --no_ref
```

### 2.15 가상 생성 시뮬레이션 (`--mock`)
ComfyUI 서버를 구동하지 않고도 0.001초 만에 더미 WebP 파일을 생성하여 파일명, 폴더 경로, 포즈 매핑의 엔드투엔드 파이프라인 무결성을 초고속 검증합니다.
```bash
python -u flux_batch_generator.py -r don -c all -p 000,001 --mock
```

### 2.16 사전 검증 및 진단
```bash
# GPU 연산 없이 건너뜀/신규 생성 대상 및 프롬프트 미리보기 점검
python flux_batch_generator.py -r don -c all -p 000,001 --engine sdxl --dry-run

# 파이프라인 무결성 자체 진단 (FLUX 및 SDXL 동시 검증)
```

## 5. ❓ 자주 묻는 질문 (FAQ)

### Q1. 특정 파일 1개만 다시 생성하고 싶어요.
> 다시 뽑고 싶은 파일(예: `bjh_00.webp`)을 삭제한 후, `python -u flux_batch_generator.py -r don -c bjh -p 00`을 실행하시면 해당 파일만 깔끔하게 새로 생성됩니다.

### Q2. 60장 연속 배치 생성 시 VRAM이 부족하지 않나요?
> 플에파 엔진은 48GB 시스템 RAM과 RTX 4060 Ti 8GB 환경에 맞추어 `flux1-dev-Q6_K.gguf` 양자화 모델을 오프로딩 구조로 구동하므로, 메모리 누수 없이 장시간 연속 배치를 안정적으로 완주합니다.

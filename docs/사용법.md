## 1. 개요 (Overview)

플에파(PLEPA: Flux Asset Pipeline)는 차세대 12B 파운데이션 모델인 **FLUX.1 [dev]**와 **ComfyUI 로컬 비동기 API**를 결합하여, 챗봇 및 비주얼 노벨용 80종 캐릭터 에셋을 고해상도로 일괄 자동 생성하는 최첨단 배치 생성 시스템입니다.

---

## 2. ⚡ 가장 많이 쓰는 명령어 (치트시트)

> [!IMPORTANT]
> 윈도우 환경에서 터미널 출력 버퍼링과 한글 잘림을 방지하기 위해 항상 **`python -u`** 옵션으로 실행하는 것을 권장합니다.

### 2.1 원클릭 전체 일괄 생성
```bash
# don 프로젝트의 모든 캐릭터(6명)를 대상으로 80종 전체 에셋 일괄 생성
python -u flux_batch_generator.py -r don -c all -p all

# don 프로젝트의 모든 캐릭터를 대상으로 00번(평상), 01번(미소)만 빠르게 일괄 생성
python -u flux_batch_generator.py -r don -c all -p 00,01
```

### 2.2 단일 캐릭터 생성
```bash
# 특정 캐릭터 전체 80종 생성
python -u flux_batch_generator.py -r don -c bjh -p all

# 특정 캐릭터의 감정 씬(00~19) 20종만 생성
python -u flux_batch_generator.py -r don -c ksn -p emotions

# 특정 캐릭터의 H씬(40~59) 20종만 생성
python -u flux_batch_generator.py -r don -c bjh -p h_scenes

# 특정 캐릭터의 오토코노코 씬(140~159) 20종만 생성
python -u flux_batch_generator.py -r don -c shn -p otokonoko
```

### 2.3 다중 캐릭터 묶음 생성
```bash
# 쉼표로 원하는 캐릭터들만 묶어서 순차 실행
python -u flux_batch_generator.py -r don -c bjh,ksn,shn -p 00,01
```

### 2.4 스마트 건너뛰기 (`--skip-existing`)
```bash
# 이미 폴더에 정상 생성된 WebP 파일은 0초 만에 건너뛰고, 누락되거나 실패한 파일만 골라서 생성
python -u flux_batch_generator.py -r don -c all -p all --skip-existing
```

### 2.5 특정 번호 대역 지정
```bash
# 번호 범위 지정 (.. 연산자)
python -u flux_batch_generator.py -r don -c bjh -p 00..05

# 쉼표로 특정 번호만 콕 집어서 생성
python -u flux_batch_generator.py -r don -c bjh -p 00,03,05,20
```

### 2.6 배경 프리셋 변경 (`--bg-preset`)
```bash
# projects/don/background.json 에 등록된 배경 키를 감정 씬(00~19)에 일괄 적용
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --bg-preset penthouse_living
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --bg-preset room
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --bg-preset elevator
```

### 2.7 사전 검증 및 진단
```bash
# GPU 연산 없이 프롬프트 조립 결과와 파일명만 미리보기 점검
python flux_batch_generator.py -r don -c all -p 00,01 --dry-run

# 파이프라인 무결성 자체 진단
python flux_batch_generator.py --test
```

## 3. 📂 프로젝트 및 폴더 구조

에파의 멀티 프로젝트 아키텍처를 계승하여 `projects/[로스터명]/` 하위로 데이터가 완벽히 격리됩니다:

```text
projects/
└── don/                            # 로스터 (작품명)
    ├── background.json             # 작품 공통 배경 프리셋
    ├── characters/                 # 캐릭터 프로필 JSON
    │   ├── bjh.json (배지혜)
    │   ├── jhy.json (정하율)
    │   ├── ksn.json (강시내)
    │   ├── oes.json (온은서)
    │   ├── sce.json (성채은)
    │   └── shn.json (신하늘)
    ├── references/                 # 원본 레퍼런스 얼굴/작화 이미지 (*.webp)
    │   ├── bjh.webp, ksn.webp 등
    └── assets/                     # 생성된 최종 고화질 에셋 (*.webp)
        ├── bjh/
        │   ├── bjh_00.webp
        │   ├── bjh_01.webp
        │   └── bjh_genit_guide.md  # 젠잇 복사용 자동 가이드 마크다운
        └── ...
```

## 5. 💬 젠잇(Gen-IT) 에셋 등록 가이드

배치 생성이 완료되면 각 캐릭터의 `assets/[prefix]/` 폴더에 `[prefix]_genit_guide.md` 파일이 자동 생성됩니다:

1. **이미지 호출 코드**: `{{url}}bjh/bjh_00.webp` 형식으로 젠잇 프롬프트에 즉시 삽입 가능합니다.
2. **상태 매핑 가이드**: 챗봇의 시스템 프롬프트에 복사하여 특정 표정/행동 시 어떤 이미지를 출력해야 하는지 봇이 완벽히 인지하도록 만듭니다.
3. **상태창 템플릿**: 대화 턴마다 캐릭터의 호감도, 현재 의상, 장소를 동적으로 표시합니다.

## 6. ❓ 자주 묻는 질문 (FAQ)

### Q1. 특정 파일 1개만 다시 생성하고 싶어요.
> 다시 뽑고 싶은 파일(예: `bjh_00.webp`)을 삭제한 후, `python -u flux_batch_generator.py -r don -c bjh -p 00`을 실행하시면 해당 파일만 깔끔하게 새로 생성됩니다.

### Q2. 60장 연속 배치 생성 시 VRAM이 부족하지 않나요?
> 플에파 엔진은 48GB 시스템 RAM과 RTX 4060 Ti 8GB 환경에 맞추어 `flux1-dev-Q6_K.gguf` 양자화 모델을 오프로딩 구조로 구동하므로, 메모리 누수 없이 장시간 연속 배치를 안정적으로 완주합니다.

## 1. 개요 (Overview)

플에파(PLEPA: Flux Asset Pipeline)는 차세대 12B 파운데이션 모델인 **FLUX.1 [dev]**와 **ComfyUI 로컬 비동기 API**를 결합하여, 챗봇 및 비주얼 노벨용 80종 캐릭터 에셋을 고해상도로 일괄 자동 생성하는 최첨단 배치 생성 시스템입니다.

## 2. ⚡ 가장 많이 쓰는 명령어 (치트시트)

> [!IMPORTANT]
> 윈도우 환경에서 터미널 출력 버퍼링과 한글 잘림을 방지하기 위해 항상 **`python -u`** 옵션으로 실행하는 것을 권장합니다.

### 2.1 듀얼 엔진 선택 (FLUX ↔ SDXL)
플에파는 필요에 따라 **12B FLUX 서술형 자연어 모드**와 **SDXL 언홀리 9.0 쾌속 2D 셀화 모드**를 즉시 스위칭할 수 있습니다.

```bash
# [추천] SDXL 언홀리 9.0 쾌속 모드 (장당 약 14초, 60장 배치 약 14분 완료)
python -u flux_batch_generator.py -r don -c all -p all --engine sdxl

# FLUX.1 [dev] GGUF 기본 모드 (장당 약 80~190초, 12B 파운데이션 묘사력)
python -u flux_batch_generator.py -r don -c all -p all --engine flux
```

### 2.2 ComfyUI 특화 품질 보정 옵션
```bash
# 1. Face Detailer 얼굴 자동 초정밀 보정 (전신 샷에서도 눈/코/입 뭉개짐 자동 복구)
python -u flux_batch_generator.py -r don -c bjh -p 00,01 --engine sdxl --face-detailer

# 2. 4x AI 초고해상도 업스케일러 통합 (4x-UltraSharp로 2K/4K급 에셋 직결 출력)
python -u flux_batch_generator.py -r don -c bjh -p 00,01 --engine sdxl --upscale

# 3. 얼굴 보정 + 초고해상도 업스케일 동시 적용
python -u flux_batch_generator.py -r don -c bjh -p 00,01 --engine sdxl --face-detailer --upscale
```

### 2.3 원클릭 전체 일괄 생성
```bash
# don 프로젝트의 모든 캐릭터(6명)를 대상으로 80종 전체 에셋 일괄 생성 (SDXL 모드)
python -u flux_batch_generator.py -r don -c all -p all --engine sdxl

# don 프로젝트의 모든 캐릭터를 대상으로 00번(평상), 01번(미소)만 빠르게 일괄 생성
python -u flux_batch_generator.py -r don -c all -p 00,01 --engine sdxl
```

### 2.4 단일 캐릭터 생성
```bash
# 특정 캐릭터 전체 80종 생성 (약 18분 소요)
python -u flux_batch_generator.py -r don -c bjh -p all --engine sdxl

# 특정 캐릭터의 감정 씬(00~19) 20종만 생성 (약 4.5분 소요)
python -u flux_batch_generator.py -r don -c ksn -p emotions --engine sdxl

# 특정 캐릭터의 H씬(40~59) 20종만 생성
python -u flux_batch_generator.py -r don -c bjh -p h_scenes --engine sdxl

# 특정 캐릭터의 오토코노코 씬(140~159) 20종만 생성
python -u flux_batch_generator.py -r don -c shn -p otokonoko --engine sdxl
```

### 2.5 다중 캐릭터 묶음 생성
```bash
# 쉼표로 원하는 캐릭터들만 묶어서 순차 실행
python -u flux_batch_generator.py -r don -c bjh,ksn,shn -p 00,01 --engine sdxl
```

### 2.6 기본 동작: 빈칸만 채우기 (기존 파일 자동 보존)
플에파는 **이미 생성된 파일이 있으면 0초 만에 자동으로 건너뛰고, 누락된 빈칸 파일만 채우는 것이 기본값(Default)**입니다.
따라서 별도의 옵션 없이 실행해도 기존에 잘 뽑힌 에셋이 실수로 지워지거나 덮어씌워지지 않습니다.

```bash
# 전체 실행 시 이미 있는 파일은 건너뛰고, 없는 파일만 알아서 채움
python -u flux_batch_generator.py -r don -c all -p all --engine sdxl
```

### 2.7 파일 교체: 특정 포즈 다시 뽑아서 덮어쓰기 (`--overwrite` / `-f`)
마음에 안 드는 특정 포즈를 다른 시드로 다시 뽑아 **기존 파일을 새로운 이미지로 교체(리롤)**하고 싶을 때는 `--overwrite` (또는 `-f`) 옵션을 붙입니다.

```bash
# bjh의 00번 평상 포즈를 다시 뽑아 기존 파일 덮어쓰기
python -u flux_batch_generator.py -r don -c bjh -p 00 --engine sdxl --overwrite

# 단축 옵션 -f 사용
python -u flux_batch_generator.py -r don -c bjh -p 00,01 --engine sdxl -f
```

### 2.8 특정 번호 대역 지정
```bash
# 번호 범위 지정 (.. 연산자)
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --engine sdxl

# 쉼표로 특정 번호만 콕 집어서 생성
python -u flux_batch_generator.py -r don -c bjh -p 00,03,05,20 --engine sdxl
```

### 2.9 배경 프리셋 변경 (`--bg-preset`)
```bash
# projects/don/background.json 에 등록된 배경 키를 감정 씬(00~19)에 일괄 적용
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --engine sdxl --bg-preset penthouse_living
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --engine sdxl --bg-preset room
python -u flux_batch_generator.py -r don -c bjh -p 00..05 --engine sdxl --bg-preset elevator
```

### 2.10 사전 검증 및 진단
```bash
# GPU 연산 없이 건너뜀/신규 생성 대상 및 프롬프트 미리보기 점검
python flux_batch_generator.py -r don -c all -p 00,01 --engine sdxl --dry-run

# 파이프라인 무결성 자체 진단 (FLUX 및 SDXL 동시 검증)
python flux_batch_generator.py --test
```

## 3. 📂 프로젝트 및 폴더 구조

에파의 멀티 프로젝트 아키텍처를 계승하여 `projects/[로스터명]/` 하위로 데이터가 완벽히 격리됩니다:

```text
projects/
└── don/                            # 로스터 (작품명)
    ├── background.json             # 작품 공통 배경 프리셋
    ├── characters/                 # 캐릭터 프로필 JSON
    │   ├── bjh.json (배지혜)
    │   ├── jhy.json (정하율)
    │   ├── ksn.json (강시내)
    │   ├── oes.json (온은서)
    │   ├── sce.json (성채은)
    │   └── shn.json (신하늘)
    ├── references/                 # 원본 레퍼런스 얼굴/작화 이미지 (*.webp)
    │   ├── bjh.webp, ksn.webp 등
    └── assets/                     # 생성된 최종 고화질 에셋 (*.webp)
        ├── bjh/
        │   ├── bjh_00.webp
        │   └── bjh_01.webp
        └── ...
```

## 5. ❓ 자주 묻는 질문 (FAQ)

### Q1. 특정 파일 1개만 다시 생성하고 싶어요.
> 다시 뽑고 싶은 파일(예: `bjh_00.webp`)을 삭제한 후, `python -u flux_batch_generator.py -r don -c bjh -p 00`을 실행하시면 해당 파일만 깔끔하게 새로 생성됩니다.

### Q2. 60장 연속 배치 생성 시 VRAM이 부족하지 않나요?
> 플에파 엔진은 48GB 시스템 RAM과 RTX 4060 Ti 8GB 환경에 맞추어 `flux1-dev-Q6_K.gguf` 양자화 모델을 오프로딩 구조로 구동하므로, 메모리 누수 없이 장시간 연속 배치를 안정적으로 완주합니다.

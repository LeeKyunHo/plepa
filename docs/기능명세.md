# 플에파 (PLEPA) 기능 및 기술 명세서

> **문서 버전**: v1.0.0  
> **시스템 명칭**: 플럭스 에셋 파이프라인 (Flux Asset Pipeline / PLEPA)  
> **백엔드 엔진**: ComfyUI Local REST & WebSocket API  
> **타겟 모델**: FLUX.1 [dev] (GGUF Q6_K 양자화)

---

## 1. 시스템 개요

### 1.1 개발 목적
Stable Diffusion XL 기반의 레거시 태그 방식을 탈피하고, 차세대 12B 파운데이션 모델인 FLUX.1 [dev]의 뛰어난 언어 이해력과 사실적인 인체 해부학적 묘사력을 활용하여 고해상도 80종 캐릭터 챗봇 에셋을 완전 자동화하여 일괄 배치 생성합니다.

### 1.2 핵심 기능
1. **ComfyUI 로컬 비동기 파이프라인**: WebSocket 기반 실시간 큐 모니터링 및 REST API 연동.
2. **영문 서술형 자연어 조립 엔진**: T5-XXL 텍스트 인코더에 최적화된 프롬프트 자동 조립 (구도 ➔ 외형 ➔ 의상 ➔ 화풍 ➔ 배경).
3. **스마트 의상 격리 (Nude Exclusion)**: 탈의 및 결합 씬에서 평상시 의상 묘사를 원천 차단.
4. **프로젝트 배경 프리셋 치환**: `background.json`을 통해 감정 씬(00~19)의 배경을 작품 고유 공간으로 자동 합성.
5. **다중 캐릭터 및 로스터 자동 탐색**: 단일, 다중(쉼표), 로스터 전체(`all`) 일괄 생성 지원.
6. **스마트 건너뛰기 (`--skip-existing`)**: 이미 생성된 WebP 파일을 감지하여 누락분만 고속 생성.
7. **젠잇(Gen-IT) 연동 자동화**: 생성 완료 즉시 마크다운 호출 코드 및 상태창 템플릿 자동 빌드.

│       └── assets/              # 생성된 최종 이미지 및 젠잇 가이드 (*.webp, *.md)

### 3.2 `plepa_engine.comfy_client.ComfyClient`

ComfyUI 백엔드와의 실시간 WebSocket 세션 및 REST API 통신을 전담합니다.

- `check_connection() -> bool`: ComfyUI 서버(포트 8188) 활성화 여부 확인.
- `queue_prompt(workflow: Dict) -> str`: `/prompt` 엔드포인트에 노드 그래프를 전송하고 `prompt_id` 수신.
- `wait_for_completion(prompt_id: str) -> None`: WebSocket을 통해 `executing`, `progress` 이벤트를 수신하여 생성이 끝날 때까지 대기.
- `download_image(filename: str, output_path: Path) -> None`: `/view` 엔드포인트에서 생성된 이미지를 받아 로컬 경로에 WebP 형식으로 저장.

---

### 3.3 `plepa_engine.workflow_templates.build_flux_workflow`

ComfyUI `/prompt` 엔드포인트에 주입할 유효한 노드 그래프 딕셔너리를 생성합니다:

1. **Node 1 (`UnetLoaderGGUF`)**: Q6_K 양자화 UNet 모델 로드.
2. **Node 2 (`DualCLIPLoader`)**: T5-XXL FP8 및 CLIP-L 인코더 로드.
3. **Node 3 (`VAELoader`)**: 순정 FLUX VAE(`ae.safetensors`) 로드.
4. **Node 4 (`CLIPTextEncode`)**: 조립된 자연어 프롬프트 텍스트 인코딩.
5. **Node 5 (`FluxGuidance`)**: 플럭스 전용 가이던스 스케일 (기본: 3.5).
6. **Node 6 (`EmptySD3LatentImage`)**: 896x1152 잠재 공간 생성.
7. **Node 7 (`KSampler`)**: Euler + Simple 스케줄러 기반 24스텝 샘플링.
8. **Node 8 (`VAEDecode`)**: 최종 이미지 텐서 디코딩.
9. **Node 20 (`SaveImage`)**: 결과 파일 출력.

## 5. 종료 코드 (Exit Codes)

| 코드 | 상태 | 의미 |
| :---: | :---: | :--- |
| `0` | **성공** | 모든 요청된 에셋이 정상적으로 생성됨 (또는 건너뜀) |
| `1` | **오류** | 캐릭터 파일 부재, ComfyUI 서버 미기동, 또는 네트워크 예외 발생 |

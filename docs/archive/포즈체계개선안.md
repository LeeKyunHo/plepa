# 플에파 포즈 체계 개선안

## 현재 문제점
- 구 포즈 (000-159)와 신규 Genit 포즈 (A0-F22)가 기능적으로 겹침
- 포즈 선택 시 혼란 발생
- 중복 생성 우려

## 개선 방향

### 1. **카테고리별 명확한 분리**

#### A. 레거시 포즈 (Legacy Poses)
```
000-019: 감정 (Emotions - 20종)
020-039: 일반 포즈 (General Poses - 20종)  
040-059: H씬 (Adult Scenes - 20종)
140-159: 오토코노코 (Otokonoko - 20종)
```
**용도**: 기존 프로젝트 호환성 유지, 점진적 마이그레이션

#### B. Genit 상용 표준 (Genit Commercial Standard)
```
A0-A23: 감정 24종 (Emotions)
B1-B22: 행동 22종 (Actions)
C1-C10: 무협 특화 10종 (Wuxia)
D1-D10: 수영복 10종 (Swimsuit)
E1-E06: BDSM 6종
F1-F06: 바니걸 6종
N1-N74: 성인 46종 (Adult)
```
**용도**: 상용 배포용 표준 세트

### 4. **마이그레이션 가이드**

#### 기존 프로젝트 → Genit 표준 전환
```
레거시          →  Genit 권장
000-019 감정    →  A0-A23 감정 (더 다양함)
020-039 포즈    →  B1-B22 행동 (더 동적)
040-059 H씬     →  N1-N74 성인 (더 다양함)
```

#### 점진적 전환 전략
1. **Phase 1**: 두 시스템 병행 (현재)
2. **Phase 2**: Genit 표준 우선 추천, 레거시 하위 호환
3. **Phase 3**: 레거시는 "고급 옵션"으로 이동

### 5. **구현 우선순위**

#### 즉시 적용 가능 (Low Hanging Fruit)
- ✅ 포즈 세트 드롭다운에 카테고리 구분선 추가
- ✅ Genit 세트에 ⭐ 아이콘 추가 (추천 표시)
- ✅ 레거시 세트 이름에 "(레거시)" 접미사 추가

#### 중기 개선 (2주 이내)
- 탭 기반 UI로 전환
- 포즈 세트 JSON 재구성
- 포즈 프리뷰 기능 추가

#### 장기 목표 (1개월+)
- 포즈별 썸네일 이미지
- 드래그 앤 드롭 포즈 선택
- 프로젝트별 포즈 즐겨찾기

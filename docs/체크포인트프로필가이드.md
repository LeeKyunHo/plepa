# 체크포인트 프로필 시스템 가이드

## 개요
플에파(PLEPA)는 SDXL 체크포인트별로 최적화된 파라미터를 자동으로 적용하는 프로필 시스템을 제공합니다.

**자동 적용되는 항목:**
- ✅ 해상도 (width × height)
- ✅ 샘플링 스텝 수 (steps)
- ✅ CFG 스케일 (cfg)
- ✅ 샘플러 알고리즘 (sampler)
- ✅ 스케줄러 (scheduler)

**참고만 제공되는 항목 (자동 적용 안됨):**
- 📄 추천 품질 태그 (Positive/Negative)
- 📄 CLIP Skip 값
- 📄 추천 업스케일러
- 📄 Hires Fix 설정

## 사용 방법

### CLI에서 사용
```bash
# WAI-Illustrious 프로필 자동 적용 (1024×1344, euler_a)
python flux_batch_generator.py -c 캐릭터명 -p all --engine sdxl --ckpt "waiIllustriousSDXL_v170.safetensors"

# Unholy Mix 프로필 자동 적용 (832×1216, dpmpp_2m, CFG 5.0)
python flux_batch_generator.py -c 캐릭터명 -p all --engine sdxl --ckpt "unholyDesireMixSinister_v90.safetensors"

# 사용자가 명시한 파라미터는 프로필보다 우선
python flux_batch_generator.py -c 캐릭터명 --engine sdxl --ckpt "wai.safetensors" --width 768 --height 1024
# → 프로필 무시하고 사용자 지정값(768×1024) 사용
```

### 출력 예시
```
  체크포인트 프로필: 'WAI-Illustrious-SDXL v17' 자동 적용
============================================================
  [플에파] 듀얼 엔진 가동 모드: SDXL (waiIllustriousSDXL_v170.safetensors)
  대상 캐릭터: 총 1명 (ykn)
  캐릭터당 포즈: 총 80개 (000..079) | 총 80개 에셋
  해상도: 1024x1344 | 스텝: 25 | CFG: 6.0 | 샘플러: euler_ancestral / normal
  ...
```

## 퍼지 매칭 로직

체크포인트 파일명이 정확히 일치하지 않아도 자동으로 프로필을 찾습니다:

1. **완전 일치**: 파일명이 정확히 동일
2. **패턴 매칭**: `match_patterns`에 정의된 키워드 검색
3. **부분 매칭**: 등록된 파일명의 일부가 포함된 경우

### 예시
```
"WAI-NSFW-illustrious-v7.safetensors"
  → "illustrious" 패턴 매칭
  → WAI-Illustrious-SDXL v17 프로필 적용

"my_custom_pony_mix.safetensors"
  → "pony" 패턴 매칭
  → Pony Diffusion V6 XL 프로필 적용

"unknown_model_xyz.safetensors"
  → 매칭 실패
  → Default SDXL Profile 적용
```

## 프로필 커스터마이징

`plepa_engine/checkpoint_profiles.json` 파일을 수정하여 새로운 프로필 추가 또는 기존 프로필 수정 가능:

```json
{
  "profiles": {
    "myCustomModel_v10.safetensors": {
      "name": "My Custom Model v1.0",
      "match_patterns": ["custom", "mycustom"],
      "engine": "sdxl",
      "width": 896,
      "height": 1280,
      "steps": 30,
      "cfg": 6.5,
      "sampler": "dpmpp_2m",
      "scheduler": "karras",
      "quality_positive": "masterpiece, best quality, ultra detailed",
      "quality_negative": "bad quality, worst quality",
      "description": "커스텀 모델 설명",
      "tags": ["custom", "anime"]
    }
  }
}
```

## 주의사항

1. **품질 태그는 자동 주입되지 않습니다**  
   → 이 문서의 "추천 품질 태그"를 참고하여 캐릭터 JSON 파일의 `sdxl_positive`/`sdxl_negative`에 직접 추가하세요.

2. **프로필은 SDXL 모드에만 적용됩니다**  
   → FLUX 모드(`--engine flux`)에서는 프로필 시스템이 동작하지 않습니다.

3. **사용자 지정 파라미터가 최우선**  
   → CLI에서 명시적으로 지정한 값은 프로필보다 우선합니다.

4. **파일명 확장자는 무시됩니다**  
   → `.safetensors`, `.ckpt` 모두 동일하게 처리됩니다.

## 문제 해결

### Q: 프로필이 적용되지 않아요
A: 다음을 확인하세요:
- `--engine sdxl` 모드인가?
- `--ckpt` 파라미터를 지정했는가?
- 출력 로그에 "체크포인트 프로필: ..." 메시지가 보이는가?

### Q: 잘못된 프로필이 적용돼요
A: `debug_matching.py` 스크립트로 매칭 결과 확인:
```bash
python debug_matching.py
```

### Q: 품질 태그가 프롬프트에 없어요
A: 정상입니다. 품질 태그는 자동 주입되지 않습니다.  
   → 캐릭터 JSON 파일의 `sdxl_positive`/`sdxl_negative`에 직접 추가하세요.

# [Gen-IT Universal Framework] 젠잇 범용 콘텐츠 제작 엔진

본 폴더(`frameworks/genit/`)는 젠잇(genit.ai) 플랫폼에서 비주얼 노벨, 시뮬레이션 타이쿤, 판타지 RPG, 학원물 등 **어떤 장르의 다중 인터랙티브 콘텐츠든 쉽고 빠르게 양산할 수 있도록 설계된 마스터 템플릿(Master Boilerplate)** 보관소입니다.

---

## 📁 구성 파일 일람

| 파일명 | 역할 및 내용 |
| :--- | :--- |
| [**`MASTER_FRAMEWORK.md`**](MASTER_FRAMEWORK.md) | **[코어 룰 엔진 및 5대 탭 마스터 템플릿]**<br>• 실전 검증 10대 트러블슈팅 불변식<br>• MODULE 1~6 통합 메인 프롬프트 템플릿<br>• 듀얼 시작 설정 (입문 모드1 vs 관리자 모드2)<br>• 캐릭터 4단 장기기억 프롬프트 (500자 압축 규격)<br>• 3대 핵심 로어북 템플릿 (공간 매핑, 시스템 룰, 돌발 이벤트) |

## ⚡ 신규 프로젝트 생성 3단계 워크플로우

1. **프로젝트 폴더 생성**:
   - `projects/<신규_프로젝트명>/` 디렉토리를 생성합니다.
2. **범용틀 복사 및 치환**:
   - `frameworks/genit/MASTER_FRAMEWORK.md`와 `UNIVERSAL_STATUS.jsx`를 참조하여, 신규 프로젝트에 맞게 변수명, 세계관 용어, 캐릭터 대사만 1:1로 치환합니다.
3. **젠잇 웹 인터페이스(5대 탭)에 복사·붙여넣기**:
   - `[기본]` ➔ `[프롬프트]` ➔ `[캐릭터]` ➔ `[설정집]` ➔ `[에셋]` 순으로 입력 후 저장하면 즉시 플레이 가능한 고품질 작품이 완성됩니다.

## 🗺️ 1. 세계관 개요 (World Lore)

### "중원은 무너졌고, 천마의 깃발이 온 천하를 뒤덮었다."
- **멸망한 중원**: 절대자 **천마(天魔)**가 이끄는 마교의 파죽지세 침공 앞에 명문정파(화산, 무당, 소림, 아미, 남궁 등)와 사패천(사파 연합)은 궤멸적인 타격을 입고 사실상 멸망했습니다.
- **최후의 요새, 남만 야수궁**: 마교에 굴복하지 않고 끝까지 저항하던 정파와 사파의 잔존 세력(소수정예)은 마교와 오랜 숙적 관계였던 세외오궁 중 하나인 **남만 야수궁(南蠻 野獸宮)**으로 밀림을 뚫고 피난을 왔습니다.
- **극한의 갈등과 생존**:
  - 서로 목숨을 걸고 싸우던 **정파와 사파**가 하나의 동굴 막사에 갇혀 숨을 죽이고 있습니다.
  - 외부인을 극도로 경계하는 **남만의 토속 부족민(야수궁)**은 피난민들에게 가혹한 대가를 요구합니다.
  - 마교의 마수와 척후병들이 이미 남만의 정글 국경지대까지 턱밑까지 추격해 온 극한의 고립 상황입니다.

## 👑 2. 유저(주인공) 3대 시작 설정 시스템 (User Stance Triad)

플레이어는 채팅 시작 시 본인의 신분과 플레이 지향점을 자유롭게 선택할 수 있으며, 이에 따라 모든 등장인물의 초기 태도와 상호작용이 180도 분기됩니다.

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ [루트 1] 정파의 고수 (명분과 무공의 정점 / 고결한 구원자)                       │
│   - 포지션: 멸망 위기 중원의 마지막 희망, 명문정파 최강의 대협/검선               │
│   - 플레이 스타일: 헌신적 동료애, 사파 인물들의 유혹 극복, 도덕적 고뇌와 책임감   │
│   - 장점: 정파 히로인들의 절대적 신뢰 및 충성, 웅장한 사이다 전투                │
│                                                                                │
│ [루트 2] 사파의 잡졸 (밑바닥 생존자 / 지략과 기연의 역전극)                     │
│   - 포지션: 사파 연합의 패잔병 잡역 / 비열하지만 끈질긴 생존 본능을 지닌 무명 무사│
│   - 플레이 스타일: 정파 명문의 멸시 극복, 숨겨진 재능/기연으로 상황 뒤집기       │
│   - 장점: 오만한 아가씨들을 굴복시키는 짜릿한 하극상 쾌감, 빌드업 카타르시스     │
│                                                                                │
│ [루트 3] 남만의 지배자 (야수궁의 군주 / 절대적 권력과 거친 패도)                │
│   - 포지션: 피난 온 중원인들의 생사여탈권을 쥔 야수궁의 거친 군주               │
│   - 플레이 스타일: 피난민 통제, 오만한 중원 무인들의 복종 유도, 육체적 지배력   │
│   - 장점: 피난 온 미녀들을 거느리고 복종시키는 절대적 지배자 플레이               │
└────────────────────────────────────────────────────────────────────────────────┘
```

## 🎨 4. 배경 테마 세트 (`background.json`)

1. `default`: 울창한 밀림 속 고대 무림 요새 및 부서진 사원
2. `beast_palace`: 남만 야수궁 웅장한 부족 석조 전각, 횃불, 맹수 가죽
3. `ruined_central_plains`: 불타버린 중원 전장 폐허, 붉은 폭풍우 하늘
4. `bamboo_mist`: 안개 자욱한 황혼의 대나무 숲, 석등, 신비로운 정취
5. `cult_fortress`: 검은 흑요석 마교 본거지, 붉은 등불, 불길한 마기
6. `jungle_stream`: 열대 우림 계곡 폭포, 이끼 낀 거암, 이국적 밀림

  1. 가장 많이 쓰는 명령어 (치트시트)
==============================================================================

  ★ 주의: 터미널 출력 버퍼링을 방지하기 위해 항상 `python -u` 로 실행하세요.

  ── [★초고속 양산] SDXL (언홀리 9.0) 쾌속 모드 (장당 약 14초) ─────────────
  # 언홀리 9.0 체크포인트 + Danbooru 2D 셀화 화풍으로 쾌속 생성:
  python -u flux_batch_generator.py -r don -c all -p all --engine sdxl
  python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl  # 00,01 입력도 자동 지원
  python -u flux_batch_generator.py -r don -c bjh,ksn -p emotions --engine sdxl

  ── [고품질 서술형] FLUX.1 [dev] 기본 모드 (장당 약 80~190초) ───────────
  # 12B 파운데이션 모델 + T5 영문 서술형 프롬프트:
  python -u flux_batch_generator.py -r don -c all -p 000,001 --engine flux
  python -u flux_batch_generator.py -r don -c bjh -p emotions               # --engine 생략 시 기본값 flux

  ── [ComfyUI 특화] 얼굴 초정밀 자동 보정 (--face-detailer) ────────────────
  # 전신/카우보이 샷에서 얼굴 영역을 자동 감지해 고해상도로 정밀 복구:
  python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --face-detailer

  ── [ComfyUI 특화] 4x 초고해상도 AI 업스케일러 (--upscale) ────────────────
  # 4x-UltraSharp 모델을 파이프라인에 직결하여 초고화질 에셋 저장:
  python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl --face-detailer --upscale

  ── [원클릭] 로스터 전체 캐릭터 80종 일괄 생성 ─────────────────────────────
  python -u flux_batch_generator.py -r don -c all -p all --engine sdxl

  ── [원클릭] 로스터 전체 캐릭터 특정 포즈만 일괄 생성 (예: 000, 001번) ────────
  python -u flux_batch_generator.py -r don -c all -p 000,001 --engine sdxl

  ── 단일 캐릭터 생성 ───────────────────────────────────────────────────────
  python -u flux_batch_generator.py -r don -c bjh -p all --engine sdxl      # 배지혜 전체 80종 (약 18분 소요)
  python -u flux_batch_generator.py -r don -c ksn -p emotions --engine sdxl # 강시내 감정 20종 (약 4.5분 소요)
  python -u flux_batch_generator.py -r don -c shn -p 000,001 --engine sdxl  # 신하늘 000, 001번 (약 28초 소요)

  ── 다중 캐릭터 동시 지정 생성 (쉼표 구분) ──────────────────────────────────
  python -u flux_batch_generator.py -r don -c bjh,ksn,shn -p 000,001 --engine sdxl

  ── [기본 동작] 빈칸만 채우기 (기존 파일 자동 보존) ───────────────────────
  # 옵션 없이 실행하면 이미 생성된 파일은 0초 만에 건너뛰고 누락분만 안전하게 채웁니다:
  python -u flux_batch_generator.py -r don -c all -p all --engine sdxl

  ── [파일 교체] 특정 포즈 다시 뽑아서 덮어쓰기 (--overwrite / -f) ─────────
  # 마음에 안 드는 특정 포즈를 새로 뽑아서 덮어쓰고 싶을 때 붙입니다:
  python -u flux_batch_generator.py -r don -c bjh -p 000 --engine sdxl --overwrite
  python -u flux_batch_generator.py -r don -c bjh -p 000,001 --engine sdxl -f

  ── 섹션 및 번호 대역별 분할 생성 (키로 동일 3자리 000~159 체계) ────────
  python -u flux_batch_generator.py -r don -c bjh -p emotions --engine sdxl # 000~019 (감정 20종)
  python -u flux_batch_generator.py -r don -c bjh -p poses --engine sdxl    # 020~039 (일상/포즈 20종)
  python -u flux_batch_generator.py -r don -c bjh -p h_scenes --engine sdxl # 040~059 (H씬 20종)
  python -u flux_batch_generator.py -r don -c shn -p otokonoko --engine sdxl# 140~159 (오토코노코 씬 20종)
  python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl # 000번부터 005번까지 범위 지정
  python -u flux_batch_generator.py -r don -c bjh -p 000,005,012 --engine sdxl # 특정 번호 나열 (0, 00 입력도 호환)

  ── 배경 프리셋 변경 (감정 씬 000~019 대상) ─────────────────────────────────
  # projects/[로스터]/background.json 에 등록된 키를 지정합니다:
  python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg-preset default
  python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg-preset room
  python -u flux_batch_generator.py -r don -c bjh -p 000..005 --engine sdxl --bg-preset elevator

  ── 실행 전 미리보기 (GPU 가동 없이 건너뜀/생성 대상 점검) ───────────────
  python flux_batch_generator.py -r don -c all -p 000,001 --engine sdxl --dry-run

  ── 파이프라인 시스템 무결성 자체 진단 (FLUX + SDXL 동시 점검) ───────────
  python flux_batch_generator.py --test

  2. ComfyUI 환경 준비 및 원클릭 실행법
==============================================================================

  본 파이프라인은 로컬에서 구동 중인 ComfyUI 로컬 API (http://127.0.0.1:8188)와 통신합니다.

  1. ComfyUI 구동:
     `C:\Users\rbsgh\ComfyUI_windows_portable\run_nvidia_gpu.bat` 실행
     터미널에 `To see the GUI go to: http://127.0.0.1:8188` 문구가 뜨면 준비 완료.

  2. 필수 모델 배치 확인:
     [SDXL 모드]
     - SDXL 체크포인트: ComfyUI/models/checkpoints/unholyDesireMixSinister_v90.safetensors
     - Face Detailer   : ComfyUI/models/ultralytics/bbox/face_yolov8m.pt

     [FLUX 모드]
     - GGUF UNet       : ComfyUI/models/unet/flux1-dev-Q6_K.gguf
     - T5 인코더        : ComfyUI/models/clip/t5xxl_fp8_e4m3fn.safetensors
     - CLIP-L          : ComfyUI/models/clip/clip_l.safetensors
     - VAE             : ComfyUI/models/vae/ae.safetensors
     - 업스케일러       : ComfyUI/models/upscale_models/4x-UltraSharp.pth

  3. 프로젝트(로스터) 구조 안내
==============================================================================

  모든 작품 데이터는 `projects/[로스터]/` 하위에 독립 격리됩니다:

  projects/
  └── don/                           # 로스터 폴더명
      ├── background.json            # 프로젝트 공통 배경 프리셋
      ├── characters/                # 캐릭터 프로필 JSON
      │   ├── bjh.json (배지혜)
      │   ├── jhy.json (정하율)
      │   ├── ksn.json (강시내)
      │   ├── oes.json (온은서)
      │   ├── sce.json (성채은)
      │   └── shn.json (신하늘)
      ├── references/                # 캐릭터 원본 얼굴/작화 레퍼런스 (*.webp)
      │   └── bjh.webp, ksn.webp 등
      └── assets/                    # 생성된 이미지 결과물 (*.webp)
          ├── bjh/
          │   ├── bjh_00.webp
          │   └── bjh_01.webp
          └── ...


==============================================================================
  4. 배경 시스템과 씬 활용법
==============================================================================

  `projects/[로스터]/background.json` 예시:
  {
    "default": "modern luxury apartment living room, large panoramic window, daytime ambient lighting, blurry background",
    "room": "private luxury apartment bedroom interior, dim mood lighting, king size bed, blurry background"
  }

  • 감정 씬(00~19) 생성 시 `--bg-preset room` 옵션을 주면, 포즈 DB의 기본 단색 배경이
    해당 방 배경으로 자동 치환되어 일관된 공간감을 연출합니다.
  • H씬(40~59) 및 오토코노코 씬(140~159)은 침대/소파 등 씬 자체의 상황 서술이 우선 적용됩니다.


==============================================================================
  5. 문제 해결 (FAQ & Troubleshooting)
==============================================================================

  Q1. [오류] ComfyUI 서버(127.0.0.1:8188)에 연결할 수 없습니다.
  A1. `run_nvidia_gpu.bat`를 실행하여 서버가 켜져 있는지 확인하세요.

  Q2. 이미지가 60장 연속으로 돌다가 멈추거나 꺼지지 않나요?
  A2. 사용자의 시스템 RAM이 48GB로 매우 여유롭고 Q6_K 양자화 모델을 사용하여
      VRAM 누수 없이 안정적으로 완주합니다. 중간에 멈출 경우 `--skip-existing` 플래그를
      붙여 실행하면 멈췄던 지점부터 즉시 이어서 생성합니다.

  Q3. 터미널 글자가 깨지거나 진행도가 안 올라가요.
  A3. 윈도우 파이썬의 표준 입출력 버퍼링 때문입니다. 반드시 `python -u` 플래그를 붙여 실행하세요.

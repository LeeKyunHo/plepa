5. 주요 CLI 플래그 전체 레퍼런스 (GENERATION_OPTION_SPECS 동기화)
--------------------------------------------------------------------------------
  [기본·재생성·시드]
    -f, --overwrite              : 기존 파일이 있어도 강제 덮어쓰기 (리롤/수정 반영)
    --seed <정수>                : 특정 시드 번호 고정
    --reuse-seed                 : _batch_manifest.json에 저장된 이전 골든 시드 재사용
    --deterministic-pose-seed    : 포즈+캐릭터 해시 기반 결정론적 시드 자동 고정
    --profile <프로필명>         : 캐릭터 JSON 내 보조 의상/헤어 프로필 전환
    --naming {hybrid|code|label} : 파일명 규격 (기본 hybrid: prefix_000_라벨.webp)
    --out-dir <폴더>             : 별도 출력 루트 폴더 ({out_dir}/{roster}/{char}/)

  [로스터 조회·후처리 & Auto-QC]
    --include-legacy                     : status=legacy 구형 5개 로스터를 -r all 대상에 포함
    --face-detailer / --no-face-detailer : 얼굴 디테일러 (기본: ON)
    --hand-detailer / --no-hand-detailer : 손 디테일러 (기본: OFF)
    --freeu / --no-freeu                 : FreeU 화질 부스팅 (기본: ON)
    --upscale                            : 4x-UltraSharp AI 초해상화 (기본: OFF)
    --auto-qc / --no-qc                  : Auto-QC 자동 품질 판정 토글 (기본: ON)
    --retry-qc-failed / --no-retry-qc-failed : QC 불량 이력 자동 재시도 토글 (기본: ON)
    --max-retries <횟수>                 : Auto-QC 실패 시 최대 리롤 횟수 (기본: 3)
    --prompt-alert-threshold <횟수>      : 연속 불량 시 프롬프트 점검 경고 임계치 (기본: 2)
    --strict-censor-qc                   : 필수 노출 씬 성기 미검출 시 자동 리롤

  [자동 검열 (Phase P2.5)]
    --censor                     : 자동 검열 활성화 (무검열 원본은 {char}_origin/ 보존)
    --censor-only                : ComfyUI 없이 기존 {_origin} 원본에 0.2초 일괄 재검열
    --censor-targets <대상>      : penis (기본) | pussy | all
    --anchor-fallback            : 탐지 0건 시 DB 안전 앵커 폴백 허용 (기본: OFF)
    --censor-style <스타일>      : 총 11종 선택 가능
      * white_silhouette (기본)  * black_silhouette     * manga_bar
      * manga_glow               * silhouette           * bar / wide_bar
      * slim_bar                 * shadow               * mosaic
      * debug_bbox (신뢰도·BBox 진단 시각화 모드)

  [체크포인트·LoRA·배경·IP-Adapter·디버깅]
    --ckpt <체크포인트파일>      : 커스텀 SDXL 체크포인트 (checkpoint_profiles 자동 연동)
    --ckpt-tag <태그>            : 비교용 서브폴더 태그 (assets/{prefix}/ckpt_{태그}/ 분리 저장)
    --lora <파일명[,파일명:강도]> : SDXL LoRA 동적 체이닝 ('none'=비활성, 빈값=캐릭터 JSON 사용)
    --lora-weight <실수>         : LoRA 기본 강도 오버라이드 (미지정 시 캐릭터 설정 또는 0.8)
    --steps / --cfg / --sampler / --scheduler / --width / --height
    --bg <영문태그>              : 즉석 커스텀 배경 문장 직접 주입
    --bg-preset <키>             : projects/{roster}/background.json 프리셋 키 지정
    --custom-pos / --custom-neg  : 추가 긍정/부정 태그 결합 (`--custom_pos`/`--custom_neg` 호환)
    --use-ref / --ref-weight <w> : IP-Adapter 참조 이미지 활성화 (기본: --no-ref)
    --dry-run                    : ComfyUI 호출·디스크 저장 없이 조립 프롬프트만 점검
    --mock                       : 0.001초 더미 WebP 생성 (E2E 파일 저장 구조 테스트)

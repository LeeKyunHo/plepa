  1. 가장 많이 쓰는 명령어 (치트시트)
==============================================================================

  ★ 기본 엔진: 별도 옵션 없이 실행하면 자동으로 SDXL (Unholy Desire Mix Sinister v9.0) 모드로 초고속 생성됩니다.
  ★ 화질 특화: 검증된 2D 애니 얼굴 미형 + Face Detailer 고해상도 안면 리터칭 지원.
  ★ 키로 호환: --char, --codes, --all-chars 문법과 플에파 문법(-c, -p) 둘 다 완벽 지원합니다.

  ── [원클릭] 작품 전체 캐릭터 생성 (감정+포즈+H씬 전부) ────────────────────
  python flux_batch_generator.py -r maid --all-chars       # 메이드 전체 캐릭터
  python flux_batch_generator.py -r don --all-chars        # don 전체 캐릭터
  python flux_batch_generator.py -r man --all-chars        # man 전체 캐릭터

  ── 단일 캐릭터 전체 에셋 생성 ──────────────────────────────────────────────
  python flux_batch_generator.py -r maid --char han        # 하나 전체 생성
  python flux_batch_generator.py -r maid --char ren        # 렌(오토코노코) 전체 생성
  python flux_batch_generator.py -r maid -c rub            # 루비 전체 생성 (-c 동일)

  ── 특정 번호만 골라서 생성 ────────────────────────────────────────────────
  python flux_batch_generator.py -r maid --char han --codes "0"         # 000번(평상) 단 1장
  python flux_batch_generator.py -r ykn --char yua,serin,sia,hayul --codes "000..010" -f  # ykn 로스터 네쌍둥이 4인 표정 11종 일괄 생성
  python flux_batch_generator.py -r maid --char han --codes "44,52"     # H씬 (기승위, 구강봉사)
  python flux_batch_generator.py -r maid --char ren --codes "144,152"   # 오토코노코 H씬

  ── [★강력추천] 18% 적응형 캡슐 와이드 솔리드 바 검열본 동시 생성 ─────────
  # 무검열 원본과 함께 1픽셀도 새어나오지 않는 검열본(*_censored.webp) 동시 생성:
  python flux_batch_generator.py -r maid --char ren --codes "144,152" --censor
  python flux_batch_generator.py -r maid --char han --codes "044,052" --censor
  # 검열 스타일 선택: --censor-style {bar(와이드기본), shadow(그림자), mosaic(모자이크)}

  ── [★신규] 에셋 파일명 형식 선택 (--naming) ───────────────────────────────
  # 1) 하이브리드 표준형 (기본값): 탐색기 정렬 + 한글 직관성 동시 확보
  python flux_batch_generator.py -r maid -c han -p 000 --naming hybrid
  # 결과: han_000_평상.webp (및 레거시 호환 han_000.webp 사본 보존)

  # 2) 기존 키로 번호형:
  python flux_batch_generator.py -r maid -c han -p 000 --naming code
  # 결과: han_000.webp

  ── [연달아 실행] 여러 캐릭터 순차 일괄 생성 (★ 작업 걸어두고 쉴 때) ───────
  # 1. 같은 프로젝트에서 특정 캐릭터들만 연달아 생성 (세미콜론 ; 사용)
  python flux_batch_generator.py -r maid --char han; python flux_batch_generator.py -r maid --char rub

  # 2. 신규 캐릭터 000번(평상)만 연달아 뽑아서 빠르게 확인할 때
  python flux_batch_generator.py -r maid --char han --codes 0; python flux_batch_generator.py -r maid --char ren --codes 0

  # 3. [PowerShell 반복문] 이름 목록만 깔끔하게 돌릴 때
  "han", "rub", "ren", "aoi" | ForEach-Object { python flux_batch_generator.py -r maid --char $_ --codes "0,44,52" --censor }

  ── 섹션별 묶음 생성 ────────────────────────────────────────────────────────
  python flux_batch_generator.py -r maid -c han -p emotions    # 000~019 감정 20종
  python flux_batch_generator.py -r maid -c han -p poses       # 020~039 착의 스킨십 20종
  python flux_batch_generator.py -r maid -c han -p h_scenes    # 040~059 여성 H씬 20종
  python flux_batch_generator.py -r maid -c ren -p otokonoko   # 140~159 오토코노코 씬 20종

  ── 특정 파일 강제 덮어쓰기 재생성 (--overwrite / -f) ──────────────────────
  # 기존에 이미 파일이 있어도 프롬프트를 고친 후 다시 뽑을 때:
  python flux_batch_generator.py -r maid --char han --codes 000 --overwrite
  python flux_batch_generator.py -r maid -c ren -p 144 -f

  ── 체크포인트 즉석 변경 (--ckpt) ──────────────────────────────────────────
  # 기본값: ntrMIXIllustriousXL_xiii.safetensors (오토코노코/체위/결합 최적화)
  # Meichi MIX로 뽑고 싶을 때:
  python flux_batch_generator.py -r maid -c han -p 000 --ckpt meichiILIghtMIXV1_meichiILUstMIXV1.safetensors

  ── 배경 분위기 변경 (감정 씬 000~019 대상) ────────────────────────────────
  python flux_batch_generator.py -r maid -c han --bg-preset night
  python flux_batch_generator.py -r maid -c han --bg "luxurious classic maid mansion lobby"

  ── 레퍼런스(IP-Adapter) 동작 (기본: 완전 비활성화 고화질 모드) ──────────────
  # 기본 상태: IP-Adapter 없이 순수 프롬프트 + 체크포인트 최고 화질로 생성됩니다.
  python flux_batch_generator.py -r hey -c mal -p 034
  # 레퍼런스 강제 주입이 필요한 경우만:
  python flux_batch_generator.py -r hey -c mal -p 000 --use-ref --ref_weight 0.4

  ── [신규] 사후 단독 4K AI 초해상화 (plepa_upscaler.py) ───────────────────
  # 이미 생성된 이미지를 디퓨전 재연산 없이 순수 4x AI 모델로 4K(4096x6144) 초고화질 변환 (2~4초 소요)
  python plepa_upscaler.py -i "projects/hey/assets/mal/mal_034_가슴파묻힘.webp"
  python plepa_upscaler.py -r hey -c mal -p 034
  # 원본 파일 직접 덮어쓰기:
  python plepa_upscaler.py -r hey -c mal -p 034 -f
  # 웹 GUI: 갤러리(/gallery)에서 이미지 클릭 후 [✨ 4K AI 업스케일] 원클릭 버튼 클릭!

  ── [신규] 다이내믹 의상 스왑 & 테마 팩 (themes/swimsuit.json 등) ───────────
  # 캐릭터 본체 외모는 유지하고 교복을 완전 박멸한 후 수영복/바니걸 등으로 자동 갈아입힘
  python flux_batch_generator.py -r hey -c mal -p D            # 수영복 7종(D01~D07) 일괄 생성
  python flux_batch_generator.py -r hey -c mal -p D01         # 수영복 전신 1장 생성
  python flux_batch_generator.py -r hey -c mal -p D --dry-run # GPU 미사용 프롬프트 사전 점검

  ── 실행 전 미리보기 (GPU 호출 없이 프롬프트/파일명 점검) ───────────────────
  python flux_batch_generator.py -r maid -c han -p all --dry-run

  ── 시스템 무결성 자체 진단 ─────────────────────────────────────────────────
  python flux_batch_generator.py --test

  5. 2D 성기 자동 검열 시스템 (--censor)
==============================================================================

  - 2D 일러스트 특화 YOLOv8 모델(`dghs-imgutils`)이 성기 노출 부위를 픽셀 단위로 정밀 검출.
  - 18% 적응형 세이프 마진 + 캡슐형 둥근 모서리 가공(Corner Radius 25~35%) 적용.
  - 단 1픽셀의 노출 누수도 없는 100% 완전 차단력(사후 재검증 detected: 0건 실증)과
    허벅지/복부의 자연스러운 인체 곡선미 95% 이상 보존.
  - 무검열 원본(`*_라벨.webp`)은 그대로 보존하고, 검열본(`*_라벨_censored.webp`)을 별도 생성.


==============================================================================
  6. 문제 해결 (FAQ & Troubleshooting)
==============================================================================

  Q1. "Port 8188 is already in use" 에러가 납니다.
    ➔ 이미 백그라운드나 다른 창에서 ComfyUI가 실행 중입니다. 새로 켤 필요 없이 바로 생성 명령을 치시면 됩니다.
    ➔ 완전히 먹통일 때 강제 재시작:
       Get-NetTCPConnection -LocalPort 8188 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

  Q2. 파일이 건너뛰어지고(skip) 생성이 안 됩니다.
    ➔ 이미 대상 `.webp` 파일이 디스크에 존재하기 때문입니다. 새로 뽑으려면 명령어 뒤에 `--overwrite` (또는 `-f`)를 붙이세요.

  Q3. 터미널 한글 깨짐 방지:
    ➔ 파이프라인 내부에서 UTF-8 자동 처리가 적용되어 있으므로 안심하고 사용하시면 됩니다.

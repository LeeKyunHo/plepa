  1. 가장 많이 쓰는 명령어 (원클릭 치트시트)
==============================================================================

  ── [0] ⚡ 실전 핵심 치트코드 원클릭 모음 (골든 시드 · 엄격 리롤 · 전수 감사 · 시스템 진단) ──
  # 🩺 시스템 10단계 통합 무결성 자가 진단 (포즈DB, 캐릭터, 파이프라인, 검열, Auto-QC, ComfyUI 등 전수 점검)
  python batch_generator.py --test

  # 🎯 1초 에셋 전수 감사 (완비율, 누락 포즈, _origin 백업 현황 1초 출력)
  python batch_generator.py -r campus --audit

  # 🌟 10대 대표 골든 샘플러 (핵심 10종만 고속 검증: 감정2, 일상2, 스킨십1, 이벤트2, 로맨스1, H씬2)
  python batch_generator.py -r campus -c aya -p sample10

  # 🔒 골든 시드 고정 재생성 (기존 매니페스트 시드를 고정해 동일 구도로 의상/프롬프트만 미세 재생성)
  python batch_generator.py -r campus -c aya -p 000..019 --reuse-seed -f

  # 🛡️ 필수 성인 노출/결합 씬 성기 미탐지(구도 이탈) 시 자동 리롤
  python batch_generator.py -r campus -c aya -p h_scenes --censor --strict-censor-qc

  # 🚀 ComfyUI 호출 없이 기존 에셋 초고속(0.2초) 일괄 실루엣 소급 검열
  python batch_generator.py -r campus --all-chars -p all --censor-only



  ── [1] 작품(로스터) 전체 캐릭터 V2 표준 에셋 일괄 생성 + 자동 실루엣 검열 ──
  python batch_generator.py -r campus --all-chars -p all --censor   # 캠퍼스 6인 전원 (1인당 106종)
  python batch_generator.py -r spy --all-chars -p all --censor      # 스파이 살롱 10인 전원
  python batch_generator.py -r maid --all-chars -p all --censor     # 메이드 카페 전원

  ── [2] 단일 캐릭터 전체 에셋 생성 (성별에 맞춰 오토코노코 자동 매핑) ──
  python batch_generator.py -r campus -c aya -p all --censor        # 아야 (여성 108종: 000~052, 060~063, 080~127, 130~132)
  python batch_generator.py -r campus -c mio -p all --censor        # 미오 (오토코노코 108종: 000~052, 060~063, 150~197, 133~135)
  python batch_generator.py -r spy -c chl -p all --censor           # 클로에 전체 생성

  ── [3] 특정 포즈 번호만 골라서 생성 / 강제 덮어쓰기 (--overwrite / -f) ──
  python batch_generator.py -r campus -c aya -p 000                 # 000번(평상) 단 1장 테스트
  python batch_generator.py -r campus -c aya -p 051,060,061 -f      # 051(공부/연구), 060(딥키스), 061(알몸키스) 재생성
  python batch_generator.py -r campus -c all -p 130 -f --censor     # 6인 전원 130번(오토코노코는 133번 자동변환) 재생성
  python batch_generator.py -r campus -c aya -p "080..091" --censor # 정상위/후배위/기승위 구간만 생성

  ── [4] 섹션별 및 골든 샘플러 묶음 생성 ─────────────────────────────────────
  python batch_generator.py -r campus -c aya -p sample10           # 10대 대표 골든 샘플러 (감정2, 일상2, 스킨십1, 이벤트2, 로맨스1, H씬2)
  python batch_generator.py -r campus -c aya -p emotions            # 000~019 감정 20종
  python batch_generator.py -r campus -c aya -p poses               # 020~039 일상/스킨십 20종
  python batch_generator.py -r campus -c aya -p events              # 040~052 이벤트 씬
  python batch_generator.py -r campus -c aya -p romance             # 060~063 로맨스 4종 (딥키스/알몸키스/허그/스푸닝)
  python batch_generator.py -r campus -c aya -p h_scenes --censor   # 080~130 여성 성인 H씬
  python batch_generator.py -r campus -c mio -p otokonoko --censor  # 150~200 오토코노코 성인 H씬

  ── [5] 특수 테마 의상 팩 개별 생성 (수영복 / 바니걸 / BDSM / 무협 / 첩보) ──
  python batch_generator.py -r spy -c chl -p swimsuit               # 수영복 팩 7종 (D01~D07)
  python batch_generator.py -r spy -c chl -p bunny                  # 바니걸 팩 7종 (F01~F07)
  python batch_generator.py -r spy -c chl -p bdsm                   # BDSM 팩 8종 (E01~E08)
  python batch_generator.py -r spy -c chl -p S01..S10               # 첩보 살롱 전용 10종

  ── [6] 정밀 외곽선 화이트 실루엣 검열 (--censor & --censor-only) ──────────
  # • 검열본은 assets/{char}/에 교체 배치되고, 무검열 원본은 assets/{char}_origin/에 무손실 백업됩니다.
  # • 이미 생성된 에셋들을 ComfyUI 호출 없이 0.2초 만에 소급 검열할 때:
  python batch_generator.py -r campus -c aya -p all --censor-only
  python batch_generator.py -r campus --all-chars -p all --censor-only
  # • 검열 스타일 변경(기본값: white_silhouette):
  #   --censor-style {white_silhouette, silhouette, bar, shadow, mosaic}

  ── [7] Auto-QC 자동 품질 검수, 골든 시드 고정 재생성 & 엄격 검열 리롤 ───────
  # • 색감 과포화, 남성 분신, 단독 씬 남성 난입 감지 시 시드를 바꿔 자동 재생성(기본 3회):
  python batch_generator.py -r campus -c aya -p 034 --max-retries 5 # 최대 5회까지 리롤 허용
  python batch_generator.py -r campus -c aya -p 034 --no-qc         # Auto-QC 비활성화 (1회 강제 생성)
  # • _batch_manifest.json의 이전 골든 시드를 고정 재사용하여 구도 유지 채색/재생성:
  python batch_generator.py -r campus -c aya -p 000..019 --reuse-seed
  # • 필수 성인 노출/결합 씬에서 성기 미탐지(구도 이탈) 시 자동 리롤:
  python batch_generator.py -r campus -c aya -p h_scenes --censor --strict-censor-qc
  # • Auto-QC 리롤 한도 초과 결함 추적 및 배치 최종 포즈 수정 권장 종합 보고서:
  #   최대 재시도(3회) 후에도 Auto-QC를 통과하지 못한 이미지는 강제 저장 후
  #   캐릭터별 및 전체 최종 종합 보고서에 결함 포즈 목록과 사유를 정리하고,
  #   포즈 프롬프트 수정을 권장하는 안내 메시지를 자동 출력합니다.

  ── [8] 1초 에셋 전수 감사, 사전 점검(Precheck), kiro 동기화 및 AI 스냅샷 ────
  python batch_generator.py -r campus --audit                       # 캠퍼스 로스터 전원 완비율, 누락 포즈, _origin 백업 1초 감사
  .\.venv\Scripts\python.exe -m plepa_engine.precheck -r campus     # 캠퍼스 로스터 5단계 사전 점검
  .\.venv\Scripts\python.exe -m plepa_engine.precheck -r spy        # 스파이 로스터 5단계 사전 점검
  python scripts/sync_to_kiro.py --dry-run                          # kiro 동기화 시뮬레이션
  python scripts/sync_to_kiro.py                                    # plepa 골든 스테이트를 kiro로 전파
  python scripts/export_context.py                                  # 외부 AI(Gemini Notebook 등) 코드 리뷰용 3-Tier 스냅샷 생성
  python scripts/export_context.py --full-code                      # Tier 2 핵심 모듈 원문(40_CORE_CODE.md) 포함 번들링

  2. V2 포즈 번호 체계 요약 (오토코노코 +70 대칭 법칙)
==============================================================================

  • 000 ~ 019 : 공용 감정/표정 20종 (평상, 미소, 활짝웃음, 수줍은홍조, 토라짐 등)
  • 020 ~ 039 : 공용 일상/스킨십/샤워 20종 (윙크브이, 손하트, 벽치기, 착의애무, 샤워뒤태 등)
  • 040 ~ 047 : 공용 스토리 이벤트 8종 (덮쳐짐, 이끌기, 끌려감, 침대숙면, 목욕중, 결혼식 등)
  • 048 ~ 052 : 로스터별 테마 이벤트 5종 (캠퍼스: 048 카페, 049 도서관, 050 벤치, 051 공부/연구, 052 축제)
  • 060 ~ 063 : 공용 로맨스 4종 (060 딥키스, 061 알몸키스, 062 허그, 063 스푸닝)
  • 080 ~ 127 : 여성 기본 성인 H-씬 48종 (체위별 약/강/절정/사후, 착의 성교, 구강/가슴 봉사 등)
  • 130 ~ 132 : 여성 로스터 특수 성인 H-씬 3종 (130 빈강의실 섹스, 131 보건실 침대섹스, 132 화장실펠라)
  • 133 ~ 135 : 오토코노코 로스터 특수 성인 H-씬 3종 (여성 130~132에 1:1 대칭되는 오토코노코 전용 성인 씬)
  • 150 ~ 197 : 오토코노코 기본 성인 H-씬 48종 (여성 080~127에 정확히 +70을 더한 1:1 대칭 번호)

  3. 에셋 파일명 및 폴더 구조
==============================================================================

  • 기본 저장 경로 : projects/{roster}/assets/{char}/{char}_{code}_{label}.webp
    (예: projects/campus/assets/aya/aya_000_평상.webp, aya_060_딥키스.webp)
  • 검열 원본 백업 : projects/{roster}/assets/{char}_origin/{char}_{code}_{label}.webp
    (--censor 또는 --censor-only 실행 시 노출이 감지된 성인/탈의 씬의 무검열 원본만 분리 보관)
  • 웹 GUI 갤러리 : run_gui.bat 더블클릭 (http://localhost:8080)
    - 라이트박스 뷰어에서 [🔄 리롤], [👁️ 원본/검열본 토글], [⏪ 무검열 복원] 1클릭 지원
    - Genit 상용 규격 원클릭 패키징 및 _genit_prompt_sheet.md 프롬프트 매핑 시트 자동 생성

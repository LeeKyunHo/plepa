  1. 가장 많이 쓰는 명령어 (치트시트)
==============================================================================

  ★ 주의: 터미널 출력 버퍼링을 방지하기 위해 항상 `python -u` 로 실행하세요.

  ── [원클릭] 로스터 전체 캐릭터 80종 일괄 생성 ─────────────────────────────
  python -u flux_batch_generator.py -r don -c all -p all

  ── [원클릭] 로스터 전체 캐릭터 특정 포즈만 일괄 생성 (예: 00, 01번) ──────────
  python -u flux_batch_generator.py -r don -c all -p 00,01

  ── 단일 캐릭터 생성 ───────────────────────────────────────────────────────
  python -u flux_batch_generator.py -r don -c bjh -p all           # 배지혜 전체 80종
  python -u flux_batch_generator.py -r don -c ksn -p emotions      # 강시내 감정 20종(00~19)
  python -u flux_batch_generator.py -r don -c shn -p 00,01         # 신하늘 00, 01번

  ── 다중 캐릭터 동시 지정 생성 (쉼표 구분) ──────────────────────────────────
  python -u flux_batch_generator.py -r don -c bjh,ksn,shn -p 00,01

  ── [강력 추천] 기존 생성 파일 건너뛰고 누락분만 생성 (--skip-existing) ───
  # 작업이 중간에 중단되었거나, 새 캐릭터/포즈만 추가로 뽑을 때:
  python -u flux_batch_generator.py -r don -c all -p all --skip-existing

  ── 섹션 및 번호 대역별 분할 생성 ──────────────────────────────────────────
  python -u flux_batch_generator.py -r don -c bjh -p emotions      # 00~19 (감정 20종)
  python -u flux_batch_generator.py -r don -c bjh -p poses         # 20~39 (일상/포즈 20종)
  python -u flux_batch_generator.py -r don -c bjh -p h_scenes      # 40~59 (H씬 20종)
  python -u flux_batch_generator.py -r don -c shn -p otokonoko     # 140~159 (오토코노코 씬 20종)
  python -u flux_batch_generator.py -r don -c bjh -p 00..05        # 00번부터 05번까지 범위 지정
  python -u flux_batch_generator.py -r don -c bjh -p 00,05,12      # 특정 번호만 쉼표로 나열

  ── 배경 프리셋 변경 (감정 씬 00~19 대상) ─────────────────────────────────
  # projects/[로스터]/background.json 에 등록된 키를 지정합니다:
  python -u flux_batch_generator.py -r don -c bjh -p 00..05 --bg-preset default
  python -u flux_batch_generator.py -r don -c bjh -p 00..05 --bg-preset room
  python -u flux_batch_generator.py -r don -c bjh -p 00..05 --bg-preset elevator

  ── 특정 파일 1개만 다시 만들기 (재생성) ──────────────────────────────────
  # 1. 다시 만들고 싶은 webp 파일을 삭제합니다:
  Remove-Item "projects\don\assets\bjh\bjh_00.webp"
  # 2. 해당 번호를 실행하면 삭제된 파일만 새로 생성됩니다:
  python -u flux_batch_generator.py -r don -c bjh -p 00

  ── 실행 전 미리보기 (GPU 가동 없이 프롬프트/파일명만 점검) ───────────────
  python flux_batch_generator.py -r don -c all -p 00,01 --dry-run

  ── 파이프라인 시스템 무결성 자체 진단 ─────────────────────────────────────
  python flux_batch_generator.py --test

  2. ComfyUI 환경 준비 및 원클릭 실행법
==============================================================================

  본 파이프라인은 로컬에서 구동 중인 ComfyUI 로컬 API (http://127.0.0.1:8188)와 통신합니다.

  1. ComfyUI 구동:
     `C:\Users\rbsgh\ComfyUI_windows_portable\run_nvidia_gpu.bat` 실행
     터미널에 `To see the GUI go to: http://127.0.0.1:8188` 문구가 뜨면 준비 완료.

  2. 필수 모델 배치 확인:
     - GGUF UNet : ComfyUI/models/unet/flux1-dev-Q6_K.gguf
     - T5 인코더  : ComfyUI/models/clip/t5xxl_fp8_e4m3fn.safetensors
     - CLIP-L    : ComfyUI/models/clip/clip_l.safetensors
     - VAE       : ComfyUI/models/vae/ae.safetensors
     - 업스케일러 : ComfyUI/models/upscale_models/4x-UltraSharp.pth

  3. 프로젝트(로스터) 구조 안내
==============================================================================

  모든 작품 데이터는 `projects/[로스터]/` 하위에 독립 격리됩니다:

  projects/
  └── don/                           # 로스터 폴더명
      ├── background.json            # 프로젝트 공통 배경 프리셋
      ├── characters/                # 캐릭터 프로필 JSON
      │   ├── bjh.json (배지혜)
      │   ├── jhy.json (정하율)
      │   ├── ksn.json (강시내)
      │   ├── oes.json (온은서)
      │   ├── sce.json (성채은)
      │   └── shn.json (신하늘)
      ├── references/                # 캐릭터 원본 얼굴/작화 레퍼런스 (*.webp)
      │   └── bjh.webp, ksn.webp 등
      └── assets/                    # 생성된 이미지 결과물 (*.webp)
          ├── bjh/
          │   ├── bjh_00.webp
          │   ├── bjh_01.webp
          │   └── bjh_genit_guide.md # 젠잇 복사용 자동 가이드
          └── ...

  4. 배경 시스템과 씬 활용법
==============================================================================

  `projects/[로스터]/background.json` 예시:
  {
    "default": "modern luxury apartment living room, large panoramic window, daytime ambient lighting, blurry background",
    "room": "private luxury apartment bedroom interior, dim mood lighting, king size bed, blurry background"
  }

  • 감정 씬(00~19) 생성 시 `--bg-preset room` 옵션을 주면, 포즈 DB의 기본 단색 배경이
    해당 방 배경으로 자동 치환되어 일관된 공간감을 연출합니다.
  • H씬(40~59) 및 오토코노코 씬(140~159)은 침대/소파 등 씬 자체의 상황 서술이 우선 적용됩니다.


==============================================================================
  5. 젠잇(Gen-IT)에 에셋 등록하기
==============================================================================

  배치 생성이 완료되면 각 캐릭터 폴더에 `[캐릭터코드]_genit_guide.md` 파일이 자동 생성됩니다:
  (예: `projects\don\assets\bjh\bjh_genit_guide.md`)

  1. "이미지 호출 코드" 블록을 복사하여 젠잇 챗봇 프롬프트에 붙여넣습니다.
  2. "상태 매핑 가이드" 블록을 복사하여 챗봇 시스템 프롬프트의 상황별 이미지 출력 규칙에 적용합니다.
  3. "상태창 템플릿"을 복사하여 대화 턴마다 캐릭터의 호감도/의상 상태를 갱신합니다.


==============================================================================
  6. 문제 해결 (FAQ & Troubleshooting)
==============================================================================

  Q1. [오류] ComfyUI 서버(127.0.0.1:8188)에 연결할 수 없습니다.
  A1. `run_nvidia_gpu.bat`를 실행하여 서버가 켜져 있는지 확인하세요.

  Q2. 이미지가 60장 연속으로 돌다가 멈추거나 꺼지지 않나요?
  A2. 사용자의 시스템 RAM이 48GB로 매우 여유롭고 Q6_K 양자화 모델을 사용하여
      VRAM 누수 없이 안정적으로 완주합니다. 중간에 멈출 경우 `--skip-existing` 플래그를
      붙여 실행하면 멈췄던 지점부터 즉시 이어서 생성합니다.

  Q3. 터미널 글자가 깨지거나 진행도가 안 올라가요.
  A3. 윈도우 파이썬의 표준 입출력 버퍼링 때문입니다. 반드시 `python -u` 플래그를 붙여 실행하세요.
